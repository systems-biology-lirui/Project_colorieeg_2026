## 3. 结论与科学发现

### 👤 被试 test001
*   **FACE 类别**：临近区域有 **1** 个通道具有显著的 Color-Gray 差异；全脑共检测到 **9** 个显著通道（在静态玻璃脑图上表现为红蓝色大点，不显著点画为小灰点）。
*   **OBJECT 类别**：临近区域有 **3** 个通道具有显著的 Color-Gray 差异；全脑共检测到 **9** 个显著通道（在静态玻璃脑图上表现为红蓝色大点，不显著点画为小灰点）。
*   **PLACE 类别**：临近区域有 **0** 个通道具有显著的 Color-Gray 差异；全脑共检测到 **7** 个显著通道（在静态玻璃脑图上表现为红蓝色大点，不显著点画为小灰点）。
