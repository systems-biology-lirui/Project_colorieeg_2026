# fMRI 多模态 (ERP & High Gamma) 与四类别联合分析报告

此报告总结了 5 位被试在四个类别（Face、Object、Body、Place）下，**ERP** 与 **High Gamma (70-150Hz)** 两脑电信号模态下的激活对齐与显著电极响应统计差异。
注：`test002` 与 `test005` 分类别直接借用了 `test001` 的激活峰值坐标。由于 fMRI 实验中无单独 Body 条件，其对应峰值基准均借用全局 `Color_vs_Grey` 峰值坐标。项目结果保存在独立的 `category_multimodal` 文件夹下。

## 3. 结论与科学发现

### 👤 被试 test001
#### 刺激类别: FACE
*   **ERP 模态**：临近有 **1** 个显著通道；全脑共有 **9** 个显著通道。
*   **High Gamma 模态**：临近有 **0** 个显著通道；全脑共有 **2** 个显著通道。
#### 刺激类别: OBJECT

*   **ERP 模态**：临近有 **11** 个显著通道；全脑共有 **14** 个显著通道。
*   **High Gamma 模态**：临近有 **3** 个显著通道；全脑共有 **7** 个显著通道。

*   **ERP 模态**：临近有 **0** 个显著通道；全脑共有 **7** 个显著通道。
*   **High Gamma 模态**：临近有 **0** 个显著通道；全脑共有 **8** 个显著通道。
