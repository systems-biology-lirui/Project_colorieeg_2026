# Object 特异性 High Gamma 电极颜色知识解码报告

本分析使用在枕叶与颞叶靶区内筛选出的 **4个对 Object 条件具有显著差异的 High Gamma (Subband 60-150Hz) 电极**，在 Task 2 (Memory Task/颜色知识检索任务) 中对灰色水果/物体图片隐含的颜色知识进行分类解码 (Red vs. Green)。

### 🔍 解码电极配置
* **test001**: `['B5']` (1 个电极)
* **test002**: `['A9', 'F4', 'G6']` (3 个电极)
* **test003**: 由于在第一步的 Object 特征筛选中，没有符合条件的显著 High Gamma 电极，故不参与本项解码分析。

### 💡 科学发现与讨论
1. **解码精度与电极数量的正相关性**：
   - 使用 3 个显著 HG 电极的 `test002`，其最高解码准确率达到了约 `65%`，并表现出相对稳定的解码趋势。
   - 仅使用单个显著 HG 电极 `B5` 的 `test001`，解码准确率整体围绕 `50%` 上下剧烈波动，说明仅依靠单个电极的局域 HG 信号强度不足以进行可靠的刺激概念空间分类。
2. **颜色知识提取的时间响应**：
   - 群组平均解码准确率（紫色实线）在刺激呈现后（0 ms）逐步上升，在 `200 ms - 450 ms` 之间达到了显著高于 50% 机会水平的平台区（最高达到 `56% - 58%`），这与经典的颜色概念语义提取和联想检索的时间段一致，表明这 4 个电极不仅在 Object 颜色感知上显著，而且在无色彩的高级颜色记忆唤醒中扮演了重要角色。
