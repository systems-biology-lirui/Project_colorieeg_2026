# test001 fMRI Color-Patch—SEEG 分析报告

- 主候选半径：10 mm
- 去重后 10-mm 候选电极：3 个（D2、D3、D4；原始定位表含重复解剖行）
- 单被试结论只针对实际覆盖半球，不进行左右差异推断。

## 预处理与 QC

- F15：在重参考前作为重复高方差坏道排除。
- 坏段：以 epoch 内多通道 robust z 指标（阈值 6、坏道比例 15%）剔除；Task1/2/3 分别剔除 23/616（3.73%）、44/792（5.56%）、16/396（4.04%）。ERP 与高伽马使用同一 keep mask。
- 当前 decoding 为 fast exploratory mode：每项 100 次标签置换；正式统计建议增加至 1000 次或以上。

## 结论规则

1. Task1 显著：支持目标邻域颜色选择性。
2. Task2 跨水果解码显著：支持颜色知识信息。
3. Task3→Task2 泛化显著：支持感知与知识共享代码。
4. True–False 显著：解释为物体—颜色一致性/冲突，不能单独等同颜色编码。
5. 不显著：写为当前覆盖和功效下未获得证据，不写为表征不存在。

## test001 当前结果

- Task1 目标邻域颜色—灰度固定窗效应：D2/D3/D4 的 FDR 校正均未显著（最小 FDR p=0.398）。
- Task2 跨水果颜色记忆 decoding：峰值 accuracy=0.598，cluster 校正最小 p=0.257，未达显著。
- Task3 红—绿 decoding：峰值 accuracy=0.646，100 次置换 cluster 校正最小 p=0.129，未达显著。
- True–False decoding：峰值 accuracy=0.577，cluster 校正最小 p=0.069；属于边缘探索性信号，不能作为确定性结论。
- 以上结果只说明当前被试、当前电极覆盖和快速置换功效下的证据强弱，不等同于“没有颜色表征”。
