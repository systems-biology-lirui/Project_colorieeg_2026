# Color Cognition Analysis Prompt (2026-07-27)

## 需求说明

1. **项目初步了解，构建上下文**
   - `@README.md` 中有对这个项目的大致介绍。
   - `@color_cognition_pipeline` 目前主要的分析代码和结果在此板块。

2. **分离 color 选择性电极（规范一与规范二）**
   - 基于 1-150Hz 滤波信号（TFA 宽带信号，不分离 ERP/HG）：
   - **规范一**：基于信号显著差异位点
     - **策略 1**：在 4 种类别下 100-400ms 均值都有显著差异的电极。
     - **策略 2**：在单个类别 100-400ms 均值就存在显著差异的电极。
     - 解剖限制：位置必须在 `temporal_inf`、`fusiform` 等指定 ROI 范围内（需与用户提前确认准确 ROI 列表）。
   - **规范二**：基于 test001 找到的核磁 fMRI Color Patch 定位，寻找每个被试在附近的电极位点。

3. **电极位点展示**
   - 展示上述电极位点在玻璃脑上的分布图。
   - 展示每个被试/整体上规范一与规范二电极的重叠/交集关系（如两圆维恩图/重叠图）。

4. **记忆颜色信号分析（交集位点）**
   - 将不同电极位点的信号作为样本进行统计（使用 ANOVA 做 4 种灰色水果比较: task2 的 4 种灰色水果）。
   - 检验信号幅度上对不同记忆颜色是否存在显著差异。

5. **时频分析与多频段显著性比较**
   - 在每个 trial 上以 10Hz 为 step 进行时频分析（1-150Hz / 多频段）。
   - 在不同频段比较 4 种记忆颜色的显著性差异。

6. **单通道 Decoding 与时空渐变可视化**
   - 将多频段作为特征，在单通道上进行 decoding，绘制 decoding 正确率随时间变化的曲线。
   - 将所有电极位点的正确率曲线绘制在一张图上，线条颜色根据 Y 轴坐标（从后到前，Posterior to Anterior）由蓝变红。
