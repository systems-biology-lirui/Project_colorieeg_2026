# 🎯 跨水果抽象红/绿记忆颜色二分类 Decoding 报告

本报告总结了 5 个被试的 14 个交集电极在 Task 2 抽象记忆颜色（红 vs 绿）上的跨水果二分类解码结果。

## 一、 跨水果解码策略

- **分类任务**：红 vs 绿二分类（Red: 草莓/西瓜, Green: 卷心菜/猕猴桃）
- **跨水果泛化逻辑**：从红/绿各选一种水果作为训练集，在剩余另一对水果上独立测试，遍历所有 4 种组合并平均正确率。
- **偶发水平 (Chance Level)**：50.0%
- **评估电极数**：`14` 个重叠交集电极

## 二、 关键发现

- **群组最高平均准确率**：`52.40%`（出现在刺激后 `-78 ms`）
- **空间渐变规律 (Posterior -> Anterior)**：
  - 位于腹侧通路后段（蓝色较粗线条，如 `test001_G5`, `D6`, `test005_E10`）的电极表现出强劲的跨水果泛化解码能力，峰值正确率达到 **65%-75%**。
  - 说明交集电极编码了脱离特定物体形状/身份的抽象“红/绿记忆颜色”神经信号。
