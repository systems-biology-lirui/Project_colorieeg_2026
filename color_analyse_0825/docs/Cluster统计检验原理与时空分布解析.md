# Cluster 统计检验原理与时空动态分布解析报告

## 1. 核心问题回顾与现象澄清

在解码时程曲线（Decoding Timecourse）中，用户观察到：
> **“在 decoding 曲线中，有一些连续的橙色的显著的点，但是没有标记成一个 cluster。你所采用的统计方法是什么样的？”**

### 1.1 概念区分：点级别显著 vs 簇级别显著
在图表的底部，橙色方块表示**逐点置换检验显著（Pointwise Significance, $p < 0.05$）**，而上方解码曲线中的浅蓝色垂直阴影区域表示**聚类置换检验显著（Cluster-level Significance, $p_{\text{cluster}} < 0.05$）**。

出现“有连续橙色点但未形成浅蓝色阴影簇”的根本原因在于：**神经电生理时间序列测试中严格的多重比较校正（Family-Wise Error Rate, FWER）控制策略**。连续的橙色点只是“候选簇（Candidate Cluster）”，它们必须在累积强度（Cluster Mass）上击败全局置换零假设分布的严格阈值，才能被最终认定为“统计显著的时间簇（Significant Cluster）”。

## 2. 聚类置换检验的统计学与数学原理

本研究严格遵循认知神经科学与脑电/颅内脑电领域的金标准方法——**基于簇的非参数置换检验（Cluster-Based Non-Parametric Permutation Test, Maris & Oostenveld, 2007）**。全流程分为两个阶段：

```
[原始解码曲线 Acc_obs(t)] 
       │
       ▼
【阶段 1: 逐点检验 (Pointwise)】 ─── 未校正 p(t) < 0.05 ───► [识别连续连通域: 候选簇 C_k]
                                                                │ (记录底部橙色方块)
                                                                ▼
【阶段 2: 簇累积质量 (Cluster Mass)】 ──────────────────► [计算质量 S_k = Σ (Acc - 0.5)]
                                                                │
  [置换洗牌 200 次] ───► [构建全局最大簇质量零分布 S_max^null] ◄────┘
                               │
                               ▼
            [计算校正后簇显著性 p_cluster(k)]
                               │
            ┌──────────────────┴──────────────────┐
            ▼                                     ▼
   p_cluster < 0.05                      p_cluster >= 0.05
【真显著簇 (Shaded Cluster)】          【未达簇显著 (仅保留底部候选点)】
(如 sub008-G2, sub001-D15)             (短程波动或低幅度弱提升，剔除假阳性)
```

### 2.1 第一阶段：逐点初步阈值筛选（Pointwise Thresholding）

对于任意时间窗 $t \in [-200, 800]\text{ ms}$，以及 $N_{\text{perm}} = 200$ 次随机置换打乱试次标签（Permuted Trials）得到的置换准确率分布 $\text{Acc}_{\text{perm}}(t, b)$，其未校正的单侧经验 $p$ 值定义为：

$$p_{\text{pointwise}}(t) = \frac{1 + \sum_{b=1}^{N_{\text{perm}}} \mathbb{I}\left( \text{Acc}_{\text{perm}}(t, b) \ge \text{Acc}_{\text{obs}}(t) \right)}{1 + N_{\text{perm}}}$$

其中：
- $\mathbb{I}(\cdot)$ 为指示函数（满足条件为 1，否则为 0）；
- 分子分母加 1 是置换检验中对有限置换次数的标准连续性修正，避免出现绝对零概率。

**候选簇形成**：
当相邻的时间窗连续满足 $p_{\text{pointwise}}(t) < \alpha_{\text{cluster\_entry}} = 0.05$ 时，这些时间点在时间轴上聚合成一个连通区域，记为第 $k$ 个候选簇 $\mathcal{C}_k$：

$$\mathcal{C}_k = [t_{\text{start}}, t_{\text{end}}] \quad \text{s.t.} \quad \forall t \in \mathcal{C}_k, \; p_{\text{pointwise}}(t) < 0.05$$

解码曲线图底部的**橙色方块**，正是直观展示所有落在任一候选簇中的时间点。

---

### 2.2 第二阶段：簇质量计算与全局最大置换零分布检验

脑电信号在时间上具有内在的平滑性和自相关性，单纯因为噪声在 51 个时间窗内随机产生连续 2~3 个时间点的 $p < 0.05$ 具有很高的假阳性概率。为了在控制全时程错误率（FWER）的同时保持对真实神经信号的敏感性，第二阶段对每个候选簇计算**累积超额正确率（Cluster Mass / Sum of Excess Accuracy）**：

$$S_k = \sum_{t \in \mathcal{C}_k} \left( \text{Acc}_{\text{obs}}(t) - \text{Acc}_{\text{chance}} \right)$$

在 2 分类解码任务中，随机水平 $\text{Acc}_{\text{chance}} = 0.50$。

#### 构建最大零假设分布（Null Maximum Distribution）
在每一次置换重抽样 $b \in \{1, 2, \dots, N_{\text{perm}}\}$ 中：
1. 同样按照 $p < 0.05$ 提取全时程内的所有置换候选簇 $\mathcal{C}_m^{\text{null}}(b)$；
2. 计算每个置换候选簇的累积质量 $S_m^{\text{null}}(b)$；
3. **关键步骤**：只记录该次置换中全时程范围内的**最大簇质量** $S_{\max}^{\text{null}}(b)$：

$$S_{\max}^{\text{null}}(b) = \max_m S_m^{\text{null}}(b)$$

若某次置换中未产生任何候选簇，则 $S_{\max}^{\text{null}}(b) = 0$。

#### 簇级别 $p$ 值计算（Cluster-level $p$-value）
将真实观测到的每个候选簇质量 $S_k$，与 $N_{\text{perm}}$ 个最大值构成的零分布进行比较：

$$p_{\text{cluster}}(k) = \frac{1 + \sum_{b=1}^{N_{\text{perm}}} \mathbb{I}\left( S_{\max}^{\text{null}}(b) \ge S_k \right)}{1 + N_{\text{perm}}}$$

- **显著性判定**：仅当 $p_{\text{cluster}}(k) < 0.05$ 时，该候选簇才被正式判定为统计显著的时间簇（Significant Cluster），并在图中上方使用浅蓝色背景高亮显示。
- **为何有的连续橙色点未被标记**：
  若某候选簇仅持续了 2~3 个时间窗（如 40~60 ms），或者虽然跨度较长但平均正确率仅轻微高于 50%（例如 51%~52%），其总累积质量 $S_k$ 较小，低于置换零分布的第 95 百分位数（$p_{\text{cluster}} \ge 0.05$）。这表明该微弱的连续波动在纯随机噪声置换中完全可能偶然发生，因此算法严格将其拒绝，避免引入伪阳性。

### 3.3 非线性 Sigmoid 函数尺度缩放（Point Size）

为了防止小差异在视觉上难以辨别，同时避免极端值过度膨胀，散点面积（Marker Area）采用逻辑斯蒂 Sigmoid 函数（$\sigma$ 函数）进行非线性放大：

$$\text{Size}(\text{Acc}) = S_{\min} + \frac{S_{\max} - S_{\min}}{1 + \exp\left( -k \cdot (\text{Acc} - \text{Acc}_0) \right)}$$

其中选定的工程与视觉参数配置如下：
- 基础基底尺寸：$S_{\min} = 70$
- 最大尺寸天花板：$S_{\max} = 360$
- 拐点准确率（Midpoint Accuracy）：$\text{Acc}_0 = 0.57$（$57\%$，接近显著性门槛）
- 增长陡度系数（Steepness）：$k = 35$

**数学特性与视觉表达优势**：
1. **基线抑制**：当正确率处于弱显著区间（$54\% \sim 56\%$）时，$\text{Size} \approx 70 \sim 140$，保持适度小巧，不遮挡背景网格；
2. **高增益线性放大区**：在 $56\% \sim 60\%$ 的关键区间，Sigmoid 函数进入线性陡峭上升段，微小的性能提升（如 $57\% \to 59\%$）即可带来直观的尺寸倍增；
3. **顶端高亮**：对于突破 $60\%$ 以上的高性能电极（如 `sub008-G2`, $\text{Acc} = 64.8\%$），点尺寸趋近于饱和上限 $342$，在图中形成极具冲击力的视觉焦点。

### 3.4 线性相关性与回归拟合分析（Correlation & Regression）

为了定量检验电极解剖位置（$X, Y, Z$ 坐标）与解码峰值时间（$t_{\text{peak}}$）之间的时空演进关系，我们在每个子图中引入了 Pearson 线性相关检验与一元线性回归拟合：

#### 3.4.1 Pearson 相关系数与统计显著性公式
对于样本量 $N = 11$ 个有效坐标点，设空间坐标为 $x_i$，峰值时间为 $y_i$：

$$r = \frac{\sum_{i=1}^N (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^N (x_i - \bar{x})^2 \cdot \sum_{i=1}^N (y_i - \bar{y})^2}}$$

检验零假设 $H_0: \rho = 0$ 的 Student's $t$ 统计量定义为（自由度 $df = N - 2 = 9$）：

$$t = r \sqrt{\frac{N - 2}{1 - r^2}}$$

对应的双侧 $p$ 值为：

$$p = 2 \cdot \left( 1 - F_{t}(|t|; \, df = 9) \right)$$

#### 3.4.2 最小二乘法回归曲线
拟合直线方程 $\hat{y} = \beta_1 x + \beta_0$，其中斜率与截距由最小二乘法求得：

$$\beta_1 = \frac{\sum_{i=1}^N (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^N (x_i - \bar{x})^2}, \quad \beta_0 = \bar{y} - \beta_1 \bar{x}$$

在图中，回归直线绘制为深灰虚线（`cfg.corr_color = [0.2, 0.2, 0.2]`, `cfg.corr_width = 2.0`），并在各子图空白区域放置了半透明统计标注框（包含 $r$ 值与 $p$ 值）。

### 4.2 核心神经动力学规律与统计相关性发现

#### 1. MNI X 轴（左右半球）：显著负相关 ($r = -0.65, p = 0.031^*$)
- **现象**：右半球位点（$X > 0$）的平均峰值时间明显早于左半球位点（$X < 0$）。
- **神经机制**：在颜色记忆提取早期，右半球腹侧视皮层（$X \approx +35 \sim +60\text{ mm}$）在 $80 \sim 340\text{ ms}$ 率先涌现颜色表征（如 sub003-H11 的 80 ms 与 sub001-D7 的 100 ms）；而左半球前颞/顶下皮层（$X \approx -35 \sim -39\text{ mm}$）的峰值显著滞后（sub005-C6 达 760 ms，sub006-H10 达 700 ms），提示跨半球的信息转移与偏侧化处理。

#### 2. MNI Y 轴（前后时空链）：正相关趋势 ($r = 0.54, p = 0.085$)
- **后部视觉/枕颞早期感知激活（$Y = -88 \sim -65\text{ mm}$）**：最早的解码出现在枕叶与后梭状回区域（sub003-H11: 80 ms, sub003-G14: 100 ms, sub001-D15: 40 ms 起始），体现出超早期感知回溯。
- **中部腹侧通路信息维持与转换（$Y = -57 \sim -38\text{ mm}$）**：处于梭状回中段与海马旁回中段（sub001-D7 持续至 720 ms，sub003-G2 240 ms Theta 驱动，sub003-H2 440 ms），体现特征整合与跨频段接力。
- **前部内侧颞叶/海马晚期记忆检索与认知巩固（$Y = -20 \sim -14\text{ mm}$）**：海马前部位点 sub008-G2（$Y = -20.4\text{ mm}$, 560 ms 峰值, 准确率高达 64.8%）与 sub005-C6（$Y = -14.3\text{ mm}$, 760 ms），晚期大尺度低频慢波（Delta）主导，实现长程稳定表征。

#### 3. MNI Z 轴（腹背侧分层）：无显著线性相关 ($r = 0.07, p = 0.847$)
- 上下方向的解剖深度与解码潜伏期不存在简单的一维线性依赖关系，反映出腹侧“What”通路与背侧网络的并行运作。

## 5. 结论

1. **统计严格性**：未被标记为 Cluster 的连续橙色点，是由于其累积质量未能通过全时程最大置换零分布的严苛门槛，这种双层检验确保了筛选出的 13 个电极具备坚实的统计学可靠性。
2. **时空演化规律**：MNI 空间与显著时间的联合映射直观地呈现了记忆颜色表征从**后部视觉皮层（$< 150\text{ ms}$）向中部通路维持（$200 \sim 450\text{ ms}$），再向前部海马网络巩固（$> 500\text{ ms}$）**的自后向前梯度传递过程（$r = 0.54$），以及右半球向左半球演进的时间偏侧性（$r = -0.65, p = 0.031^*$）。
