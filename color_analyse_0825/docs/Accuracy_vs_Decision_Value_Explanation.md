# 跨任务解码中“红绿水果曲线相反”与“正确率 vs 分类值”的原理剖析

本文档专门针对用户提出的疑问进行原理解析：
1. **当前代码绘制的究竟是“正确率（Accuracy）”还是“分类值（Decision Value）”？**
2. **为什么在部分通道（如 `sub007-C4`）上，红色水果与绿色水果的曲线会呈现镜面对称（刚好相反）的走势？**

---

## 一、 当前代码计算的确认：确实是【分类正确率 (Accuracy)】

当前流水线中计算的指标是**二分类预测正确率（百分比，0% ~ 100%）**，而**不是** SVM 的连续分类值（Decision Value）：

### 1. 试次级离散预测
对于时间窗 $t$ 内的任意测试试次 $i$：
$$\hat{y}_i = \text{predict}(\text{model}, x_i) \in \{0, 1\}$$
- $\hat{y}_i = 1$：分类器判定其具有**红色**神经特征；
- $\hat{y}_i = 0$：分类器判定其具有**绿色**神经特征。

### 2. 逐品类正确率的定义
各水果样本量均为 $N = 60$ 次：
- **草莓 (Strawberry, 真实隐含色为红)**:
  $$\text{Acc}_{\text{straw}}(t) = \frac{\sum_{i \in \text{straw}} \mathbb{I}(\hat{y}_i == 1)}{60}$$
- **西瓜 (Watermelon, 真实隐含色为红)**:
  $$\text{Acc}_{\text{water}}(t) = \frac{\sum_{i \in \text{water}} \mathbb{I}(\hat{y}_i == 1)}{60}$$
- **卷心菜 (Cabbage, 真实隐含色为绿)**:
  $$\text{Acc}_{\text{cabb}}(t) = \frac{\sum_{i \in \text{cabb}} \mathbb{I}(\hat{y}_i == 0)}{60}$$
- **猕猴桃 (Kiwi, 真实隐含色为绿)**:
  $$\text{Acc}_{\text{kiwi}}(t) = \frac{\sum_{i \in \text{kiwi}} \mathbb{I}(\hat{y}_i == 0)}{60}$$

## 二、 为什么在无明显色觉效应的通道上，红绿水果正确率会“刚好相反”？

以通道 `sub007-C4` 为例，用户观察到：当卷心菜/猕猴桃达到 60%~65% 时，草莓/西瓜刚好跌落至 35%~40%，呈现出**围绕 50% 基准线的镜面对称（互补现象）**。

这是**二分类器在面对弱信号/无信号测试集时，受到分类器反应偏倚（Response Bias / 截距偏移）支配的必然数学现象**：

### 1. 数学互补性推导
在没有显著记忆色彩神经表征的时间段（如刺激呈现前 -200 ms 或不敏感通道）：
设此时分类器由于微小的跨任务基线漂移，在全体 240 个灰度试次中，倾向于将 $P$ 比例的样本预测为“绿色”（$\hat{y} = 0$），将 $1-P$ 比例预测为“红色”（$\hat{y} = 1$）。

由于此时各类水果的神经信号没有本质区分：
- 绿色水果（卷心菜、猕猴桃）的目标预测标签是 0，因此其正确率期望值为：
  $$\text{Acc}_{\text{Green}} \approx P$$
- 红色水果（草莓、西瓜）的目标预测标签是 1，因此其正确率期望值为：
  $$\text{Acc}_{\text{Red}} \approx 1 - P$$

两者之和恒等于 1：
$$\text{Acc}_{\text{Green}} + \text{Acc}_{\text{Red}} \approx P + (1 - P) = 100\%$$

也就是说：
- 当分类器整体偏向预测绿色（$P = 65\%$）时：绿色水果正确率为 **65%**，红色水果正确率自动被压缩为 **35%**；
- 当分类器整体偏向预测红色（$P = 40\%$）时：绿色水果正确率为 **40%**，红色水果正确率自动上升为 **60%**。

### 2. 为什么全体平均曲线（Overall Mean）不受影响？
全体平衡平均（Balanced Accuracy）：
$$\text{Acc}_{\text{mean}} = \frac{\text{Acc}_{\text{Green}} + \text{Acc}_{\text{Red}}}{2} \approx \frac{P + (1 - P)}{2} = 50\%$$
正如我们在 `sub007-C4` 图中看到的：虽然草莓西瓜在 35%、卷心菜猕猴桃在 65%，但加粗的橙色 Overall Mean 曲线**稳稳地停留在 50% 机会水平附近**！
这准确地告诉我们：**该通道在此时并没有真正的记忆色解码，红绿曲线的分离纯粹是由全局分类偏倚引起的伪分离**。

## 三、 真正产生颜色解码的通道是什么表现？

在真正具有强记忆色重现的通道（如 `sub008-C10`、`sub003-C13`）中，曲线呈现出完全不同的格局：

### 实测数据对照 (`sub008-C10` 在 440 ms):
- 草莓 (Strawberry): **63.8%**（高于 50%）
- 西瓜 (Watermelon): **72.4%**（高于 50%）
- 卷心菜 (Cabbage):  **61.2%**（高于 50%）
- 猕猴桃 (Kiwi):     **60.6%**（高于 50%）
- 全体平均 (Overall Mean): **57.7%**（达 Cluster-Mass 显著，p < 0.05）

**在有效解码的时间窗内，四种水果的正确率是同时超越 50% 机会水平的，绝非镜面对称相反**！

## 四、 两种分析维度的选择

根据您的科研意图，我们有两条可选方案：

### 方案 A: 保留【分类正确率 (Accuracy)】（当前方案）
- **优点**: 直观表达预测成功率（百分比），符合常规 Decoding 论文惯例。
- **识别方法**: 观察四条线是否**同时高于 50%**，且 Overall 加粗主线是否高于置换检验灰色阴影带。

### 方案 B: 改为绘制【连续分类决策值 (Decision Values / Margin)】
- **计算方式**: 提取 SVM 投影距离 $d_i = w^T x_i + b$。
- **物理意义**:
  - $d > 0$：大脑表征偏向物理“红色”；
  - $d < 0$：大脑表征偏向物理“绿色”。
- **预期形态**: 草莓与西瓜将在上方（正值区间），卷心菜与猕猴桃将在下方（负值区间）。

## 五、 深度探讨：GPT 提出的“跨任务偏移（Cross-Task / Domain Shift）”与本现象的完全统一

GPT 给出的“存在跨任务偏移”这一解释**非常准确，与我们在第二部分中所推导的“截距偏移 / 反应偏倚”本质上是完全相同的科学机理，分别从【数据几何分布】与【分类器决策】两个视角互为印证**。

### 1. 什么是“跨任务偏移（Domain Shift）”？
在神经科学的跨任务解码（Cross-Task Generalization / Cross-Decoding）中：
- **Task 3（训练集）**：被试观看的是高对比度、纯色块（真实的红绿物理刺激），诱发强烈的初级视觉感知反应；
- **Task 2（测试集）**：被试观看的是灰度水果线框或照片（无真实颜色），依赖高级认知网络的颜色记忆主动提取。

由于刺激物理属性（对比度、亮度、空间频率）以及认知任务状态的不同，两个任务在大脑中诱发的**全脑整体基线电位存在系统性差异**。
若设特征空间中：
- Task 3 的数据中心点为：$\boldsymbol{\mu}_3$
- Task 2 的数据中心点为：$\boldsymbol{\mu}_2$
则跨任务偏移量即为两者的整体空间均值位移：
$$\Delta \boldsymbol{\mu}_{\text{task}} = \boldsymbol{\mu}_2 - \boldsymbol{\mu}_3 \neq 0$$

### 2. 跨任务偏移如何导致“分类器截距失效”与“红绿相反”？
设 Task 3 训练出的线性 SVM 分类超平面为：
$$f(\boldsymbol{x}) = \boldsymbol{w}^T \boldsymbol{x} + b_3$$
其中权重向量 $\boldsymbol{w}$ 代表红绿颜色调谐轴方向，截距 $b_3$ 是在 Task 3 的数据分布中心选择的最优分界阈值。

当直接把这个分类超平面应用到 Task 2 的测试样本 $\boldsymbol{x}_2$ 时：
$$f(\boldsymbol{x}_2) = \boldsymbol{w}^T \boldsymbol{x}_2 + b_3 = \boldsymbol{w}^T (\boldsymbol{x}_2 - \Delta \boldsymbol{\mu}_{\text{task}}) + (b_3 + \boldsymbol{w}^T \Delta \boldsymbol{\mu}_{\text{task}})$$

注意末尾产生的附加项 $\delta b = \boldsymbol{w}^T \Delta \boldsymbol{\mu}_{\text{task}}$：
- 只要跨任务偏移向量 $\Delta \boldsymbol{\mu}_{\text{task}}$ 在分类法向量 $\boldsymbol{w}$ 方向上的投影不为 0（在真实生理实验中几乎不可能为 0）；
- 原本在 Task 3 适用的分界面 $b_3$，在 Task 2 中就会产生**严重的相对位置偏离**！

#### 几何示意图：
```text
Task 3 (训练空间: 严格居中)
             [绿色色块]           [红色色块]
                  <----- 边界 b3 ----->
-----------------------|-----------------------> 颜色轴 w

Task 2 (测试空间: 整体向“绿”侧漂移 Δμ)
    [卷心菜/猕猴桃]  [草莓/西瓜]
           \           /
            \  数据云整体左移
             \       /
   <--- 全部掉入绿色判决区 ---> | (旧边界 b3 仍在原处)
-------------------------------|-----------------------> 颜色轴 w
```

在这个图景中：
1. **数据分布视角（GPT的表述）**：Task 2 的数据云整体发生向一侧的漂移（Domain Shift）；
2. **分类器视角（我们的表述）**：分类器截距偏离实际数据中心，产生极大的全局分类偏倚（Response Bias）；
3. **最终表现**：几乎所有 Task 2 试次（无论是草莓还是猕猴桃）都被判定为“绿色”：
   - 绿色水果恰好猜中，表现为正确率高达 65% ~ 80%；
   - 红色水果全部误判为绿色，正确率被压缩至 20% ~ 35%；
   - 二者相加恒为 100%，围绕 50% 呈镜像倒挂。

### 3. 如何区分“纯任务偏移噪声”与“真颜色记忆信号”？
- **若仅有任务偏移、无记忆色表征**（如 `sub007-C4`）：
  红绿试次仅仅是在整体偏绿的背景下无差别重叠，导致各品类相反，但**平衡准确率（Balanced Accuracy，即图中的橙色 Overall Mean）严格等于 50%**。
- **若既有任务偏移、又有真实的颜色记忆表征**（如 `sub008-C10`）：
  草莓/西瓜与卷心菜/猕猴桃在特征轴上有显著的内部分离（$\boldsymbol{\mu}_{\text{red\_fruit}} \neq \boldsymbol{\mu}_{\text{green\_fruit}}$），能够克服偏移，表现为**四种水果全部高于 50%**，Overall Mean 显著高于置换检验零分布阈值。

### 4. 神经解码领域的标准处理方法
1. **采用平衡正确率（Balanced Accuracy）消除一阶偏移**（本分析已采用）：
   $$\text{Acc}_{\text{balanced}} = \frac{\text{Acc}_{\text{Red}} + \text{Acc}_{\text{Green}}}{2}$$
   数学上严格抵消全局一阶偏倚 $\delta b$，这也是为何本分析以加粗的 Overall Mean 作为首要统计推断标准。
2. **跨任务均值中心化（Task-level Demeaning / Centering）**：
   在送入分类器前，将 Task 2 的所有试次先减去 Task 2 自身的全局平均，消解 $\Delta \boldsymbol{\mu}_{\text{task}}$。
3. **无监督截距重校准（Intercept Calibration）**：
   保持权重 $\boldsymbol{w}$ 不变，在 Task 2 的未标记试次上重新寻找决策阈值中位数。
