## 二、 核心物理机制与工程方法论

### 2.1 连续全长滤波 vs. 分段 Epoch 滤波
- **痛点问题**: 早期分析若采用先切割 Epoch（如 [-500, 1000] ms）再在切片内进行带通滤波和 Hilbert 变换，会在切片头尾引入强烈的**瞬态吉布斯边缘伪影（Edge Artifacts）**。该伪影会严重污染刺激前基线期（[-300, -100] ms），导致基线绝对功率被虚假垫高，进而引起刺激后 dB 变化率普遍偏负（如 High-Gamma 出现不可思议的负 dB 伪影）。
- **0825 物理解决方案**:
  1. 在连续未截断的原始电压信号（全长持续数十分钟）上，先行进行双向无相位失真带通滤波（`filtfilt`）。
  2. 在全长信号上做连续 Hilbert 变换提取各频段的瞬时解析包络（Power Envelope）。
  3. 提取瞬时功率后，再根据 Trigger Marker 截取各 Trial 的 Epoch（[-500, 1000] ms）。
  4. 这一流程从根本上规避了边界效应，保证了基线期信号的真实物理本底。

### 2.2 0 dB 相对基线归一化原理
- **数学定义**:
  对各频段各通道各 Trial 的瞬时功率 $P(t)$，以刺激前 $[-300, -100]\text{ ms}$ 的平均功率 $P_{\text{base}}$ 为参考：
  $$P_{\text{dB}}(t) = 10 \log_{10}\left(\frac{P(t)}{P_{\text{base}}}\right)$$
  - 基线期在 dB 尺度下的均值天然锚定在 $0\text{ dB}$。
  - $P_{\text{dB}}(t) > 0$ 表示神经振荡功率相对于刺激前基线增强（Event-Related Synchronization, ERS）。
  - $P_{\text{dB}}(t) < 0$ 表示神经振荡功率相对于刺激前基线受抑制/去同步（Event-Related Desynchronization, ERD）。
- **基线有效性实测验证**:
  在 `sub001` Task 1 实测中验证了三大标准：
  1. **跨条件无偏性**: 98.78% 的通道在基线期 Color 与 Gray 之间无显著差异（$p > 0.05$），证明基线不受刺激条件前置偏差影响。
  2. **前序试次无残留**: 前一试次的刺激属性对当前试次基线无残留效应（$p > 0.05$ 占比 97.56%）。
  3. **平稳无漂移**: 基线期电压斜率在全脑电极上平均仅为 $0.003\text{ dB/s}$，高度平稳。

### 2.3 频段划分方案
采用临床与认知神经科学界公认的 6 大标准频段：
1. **Delta**: 1 – 4 Hz
2. **Theta**: 4 – 8 Hz
3. **Alpha**: 8 – 13 Hz
4. **Beta**: 13 – 30 Hz
5. **Low-Gamma**: 30 – 60 Hz（避开 50 Hz 工频干扰）
6. **High-Gamma (HFA)**: 70 – 140 Hz（避开 50 Hz 与 100 Hz 谐波，神经局部放电活动的核心指标）

## 四、 统计检验与显著通道筛选逻辑

### 4.1 类别平衡配对设计 (Category-Balanced Paired Design)
- **避免偏倚**: Task 1 包含人脸（Face）、物体（Object）、身体（Body）、场景（Place）四种高层语义类别。若直接将所有彩色图片混合与灰度图片对比，很容易被单一类别（例如人脸本身强烈的早期诱发电位）所主导，从而产生假阳性。
- **280 对严格配对**:
  - 对每个通道，构建 280 对刺激匹配：
    $$\Delta_i = P_{\text{dB, Color}}^{(i)} - P_{\text{dB, Gray}}^{(i)}, \quad i \in \{1, 2, \dots, 280\}$$
  - 人脸 70 对，物体 70 对，身体 70 对，场景 70 对。
  - 在计算整体色彩效应时，对四类别赋予等权重计算均值：
    $$\Delta_{\text{overall}} = \frac{1}{4}\sum_{c=1}^4 \Delta_{\text{cat}_c}$$

### 4.2 时间窗口设定
- **核心检验窗口**: **100 – 400 ms**。
  - 视觉皮层自 V1/V2 经 V4 到腹侧枕颞叶（VOTRC）的潜伏期约为 80–120 ms。
  - 颜色认知与类别整合的关键期在 100–400 ms。
  - 排除早期视网膜-外膝体传输延迟（0–100 ms）与晚期运动准备及语义回响（400 ms 之后）。

### 4.3 筛选标准与一致性定义
1. **置换检验 (Sign-Flip Permutation Test)**:
   - 迭代次数: 2000 次。
   - 零假设: Color 与 Gray 在每个配对样本上可随机互换符号。
   - 计算非参数两尾置换 p 值。
2. **多重比较校正**:
   - 针对单个被试的所有有效拉普拉斯通道，在各频段内采用 Benjamini-Hochberg FDR（$q < 0.05$）进行校正。
3. **一致性分类 (Concordance Type)**:
   - **`Concordant_Positive` (首选核心通道)**:
     $$\forall c \in \{\text{Face}, \text{Object}, \text{Body}, \text{Place}\}, \quad \Delta_{\text{cat}_c} > 0 \quad \text{且} \quad p_{\text{FDR}} < 0.05$$
     四类刺激在彩色下相比灰度均表现出正向增强，且整体统计显著。
   - **`Concordant_Negative`**:
     四类刺激均表现为去同步抑制（如 Alpha 频段的强烈抑制），且整体统计显著。
   - **`Discordant` (或 `Mixed`)**:
     仅在部分类别增强，而在另一些类别无响应或相反（可能反映类别特异性而非纯色彩通用效应）。

### 5.1 绘图工具规范 (`plot_channel_timecourse.m`)
- **Nature 级科研配色标准**:
  - **彩色信号 (Color)**: 暖陶土橙褐 `[0.82, 0.42, 0.16]`，填充浅透明阴影 `[0.94, 0.78, 0.68]`。
  - **灰度信号 (Gray)**: 深板岩灰 `[0.42, 0.46, 0.50]`，填充浅灰阴影 `[0.82, 0.84, 0.86]`。
  - **色彩禁忌**: **严禁使用刺眼的纯红、纯绿或纯蓝**。
- **排版布局 (1:1 左右双子图)**:
  - **左子图 (1/2 宽度)**: 全试次平均时程曲线。
    - 横轴刻度固定为: `[-300, 0, 300, 600, 900] ms`。
    - $100\text{ ms}$ 与 $400\text{ ms}$ 处绘制深灰虚线，顶部标定置换检验显著性星号（如 `***`）。
  - **右子图 (1/2 宽度)**: 四类别刺激柱状图。
    - 四组分别对应 Face, Object, Body, Place。
    - 每组左柱为彩色（橙褐），右柱为灰度（深灰）。
    - 柱顶标注显著性连线与组内星号（`* p < 0.05`, `** p < 0.01`, `*** p < 0.001`）。
- **目录存储原则**:
  - 所有出图必须分级归档存放在 `result/figures/timecourses/<sub_id>/<band>/` 下，严禁散落在根目录。
