# 跨任务截距校准 (Intercept Calibration) 与 Task 2 Split 调优方案评估

本文档针对用户提出的核心问题进行科学论证与方案评估：
> **“AUC既然是所有阈值带来的线下面积，我们是不是更合适的方式是从Task3训练的时候，固定 $w$，但是允许分类截距不同，来挑选最优的截距。并在这个过程中考虑采用在Task2不同的split，你认为这种是否合适？”**

---

## 一、 核心结论与总体评价

**结论：您的这个想法非常敏锐，且在机器学习迁移学习（Domain Adaptation）与认知神经科学跨解码领域完全成立！**

用一句话概括：
> **固定 $w$（表征轴不变），仅在目标域（Task 2）重新估计截距 $b$（阈值校准），是解决“跨任务分布漂移（Domain Shift）”最经典、最标准的方法。**

但在**具体如何挑选 $b$** 的工程与统计实现上，存在两种不同路径，其中**无监督校准**比**带标签的 Split 交叉验证**更为稳健且毫无学术争议。

---

## 二、 为什么“固定 $w$ 调 $b$”在科学上极其合理？

在跨任务解码模型中：
$$f(\boldsymbol{x}) = \boldsymbol{w}^T \boldsymbol{x} + b$$

1. **权重向量 $\boldsymbol{w}$ 的物理意义**：
   代表红-绿颜色在多频段神经振荡中的**相对调谐轴（Tuning Direction）**。由于我们研究的核心科学假设是“物理颜色感知与记忆颜色提取共享神经表征”，因此必须严格由 Task 3 训练学得，**绝不能在 Task 2 中改动 $\boldsymbol{w}$**。
2. **截距 $b$ 的物理意义**：
   代表将大脑状态切分为“红色”或“绿色”的**分类决策门槛（Baseline Criterion）**。
3. **跨任务漂移的本质**：
   从物理刺激到记忆提取，全脑基线产生了均值偏移 $\Delta \boldsymbol{\mu}$。在投影轴上，它仅仅给每个试次增加了一个固定的标量位移 $\delta = \boldsymbol{w}^T \Delta \boldsymbol{\mu}$。
   **它并没有改变 $\boldsymbol{w}$ 的方向，只是把数据整体推离了原有的截距 $b_3$！**

因此，**冻结 $\boldsymbol{w}$，仅重新校准 $b$**，从理论几何上完全对齐了跨任务神经解码的物理本质。

## 三、 两种挑选截距 $b$ 的方案对比

### 方案 1：在 Task 2 内部使用 K-Fold Split 进行有监督调优（用户提出的设想）

#### 做法流程：
1. 固定 Task 3 训练得到的 $\boldsymbol{w}$；
2. 将 Task 2 的 240 个试次划分为 $K$ 折（如 5-Fold CV）；
3. 在每一个 Fold 内：
   - 用训练折（4/5 数据）根据水果的红绿真实标签，通过网格搜索或二分搜索找到使 Balanced Accuracy 最大的最优截距 $b^* = \arg\max_b \text{BA}(b)$；
   - 将该 $b^*$ 代入测试折（1/5 数据），计算该折的测试正确率；
4. 汇总所有折的 Out-of-fold 正确率。

#### 优缺点评估：
- **优点**：严格保持了测试集的独立性，数学上没有过拟合。
- **学术审稿风险**：
  1. **审稿人质疑独立性**：虽然做了 CV Split，但在挑选截距时实际上**使用了 Task 2 的标签信息**。审稿人可能会质疑：“这不再是纯粹的跨任务零样本迁移（Zero-shot Generalization），而变成了半监督/带偏置学习”。
  2. **置换检验计算量剧增**：为了保证统计推断的严密性，置换检验（Permutation Test）的每一轮也必须严格嵌套这套 5-Fold CV，这会使计算耗时增加 5 倍以上。

---

### 方案 2：无监督均值/中位数中心化校准（Unsupervised Baseline Centering，学术界最推荐）

这是国际神经计算与认知科学文献（如 King & Dehaene, Hebart 等）处理跨域解码截距问题最经典的方案。

#### 数学推导与做法：
由于 Task 2 的实验设计是完全正负平衡的（草莓+西瓜共 120 次，卷心菜+猕猴桃共 120 次，先验概率严格为 $P(\text{Red}) = P(\text{Green}) = 0.5$）。

我们**完全不需要知道 Task 2 任何一个试次的真实水果标签**，只需要让分类器在 Task 2 全体测试数据上的预测保持“先验无偏”即可：
$$b_{\text{calib}} = -\text{median}(\boldsymbol{w}^T \boldsymbol{x}_{\text{Task 2}})$$
或者使用无监督均值校准：
$$b_{\text{calib}} = -\text{mean}(\boldsymbol{w}^T \boldsymbol{x}_{\text{Task 2}})$$

#### 核心优势：
1. **100% 纯粹无监督，零标签泄漏**：没有使用 Task 2 的任何标签，审稿人绝对挑不出任何毛病；
2. **完全无需做 CV Split**：一步矩阵运算即可完成，计算速度极快（微秒级）；
3. **彻底消除红绿倒挂假象**：
   - 校准后，分类器在 Task 2 上预测为 Red 和 Green 的试次比例严格恢复为 50% vs 50%；
   - 之前在 `sub007-C4` 上看到的“全判为绿、红绿相反”的假象会瞬间消失，四条品类线在无效时间段全部平稳收敛在 50% 附近；
   - 在真实有效位点（如 `sub008-C10`），红绿水果由于本身存在物理差值，会同时稳健地处于 50% 以上！

## 四、 方案总结与建议

| 评估维度 | 方案 1 (带标签 Task 2 CV Split) | 方案 2 (无监督均值/中位数校准) | 方案 3 (当前的 AUC 方案) |
| :--- | :--- | :--- | :--- |
| **理论合理性** | 合理（固定 $w$ 调 $b$） | 极佳（利用实验先验平衡） | 极佳（对所有可能 $b$ 积分） |
| **是否需要标签** | 需要 Task 2 水果标签 | **完全不需要** | 完全不需要 |
| **审稿人友好度** | 中等（易被质疑使用目标域标签） | **极高（纯跨任务零监督迁移）** | 极高（标准 ROC AUC） |
| **计算复杂度** | 较高（需循环嵌套 K-Fold） | **极低（瞬间完成）** | 极低（向量化直接计算） |
| **输出指标形态** | 百分比正确率（Accuracy %） | **百分比正确率（Accuracy %）** | 线下面积（AUC, 0.5~1.0） |
