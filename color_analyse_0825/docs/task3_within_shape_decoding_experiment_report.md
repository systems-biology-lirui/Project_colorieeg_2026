# Task 3 同几何形状内部红绿神经解码与三形状平均分析报告

## 1. 实验设计与方法学原理

在之前的 Task 3 分析中，我们采用了两种策略：
1. **交叉解码（Cross-Patch Decoding, C07）**：Leave-one-patch-out（用两种形状训练，在第三种形状上测试），旨在检验跨形状的纯色彩泛化抽象表征；
2. **直接池化解码（Direct Pooled Decoding, C14）**：将所有几何形状的红绿试次混合为一个大二分类数据集进行 5 折交叉验证，反映整体色彩加工能力。

本次尝试（`C17_task3_within_shape_decoding_0825.m`）提出了第三种独立策略 —— **同形状内部独立二分类解码并取三形状平均（Within-Shape Decoding & Averaging）**：
- **控制混杂变量**：完全在相同的物理几何轮廓下对比红色与绿色（Shape 1 红 vs 绿；Shape 2 红 vs 绿；Shape 3 红 vs 绿），从根本上避免了不同几何轮廓（如圆形、正方形、三角形）之间在低阶空间频率或边缘特征上的潜在交互；
- **提高信噪比**：将三个独立形状内部训练与测试得到的平衡准确率（Balanced Accuracy）曲线进行算术平均：
  $$\text{Acc}_{\text{avg}}(t) = \frac{\text{Acc}_{\text{shape1}}(t) + \text{Acc}_{\text{shape2}}(t) + \text{Acc}_{\text{shape3}}(t)}{3}$$
- **置换检验（Permutation Test）**：
  在每个形状内部独立置换类别标签 $P = 200$ 次，并对每次置换的三形状零分布曲线求平均，获得严格受控的置换零分布 $\text{Null}(p, t)$，施加 Cluster-Mass FWE 时间簇校正（$p_{\text{cluster}} < 0.05$）。

## 2. 统计结果概览

- **分析电极总数**：全量 229 个 Task 1 独立筛选出的显著电极；
- **通过 Cluster-Mass FWE ($p < 0.05$) 严格显著通道数**：**8 个**（占比 3.5%）；
- **持续 $\ge 80\text{ ms}$（连续 $\ge 4$ 个时间点）的接近显著通道数**：**23 个**；
- **平均解码准确率峰值最高达**：**66.8%**（`sub006-F5`，在 140 ms）；单形状峰值最高超 **75%**。

## 4. 关键科学发现与时空动态特性

1. **双峰潜伏期分化（早期前馈知觉 vs 晚期表征维持）**：
   - **早期强知觉峰（140 ms）**：`sub006-F5`、`sub006-G4`（海马区）、`sub005-I3`（岛叶）在刺激呈现后 140 ms 达到 64%–67% 的强解码，体现出纯物理红绿色彩特征的极速前馈加工；
   - **中晚期表征峰（280 ms – 640 ms）**：`sub007-H5`（楔叶，280 ms）、`sub001-C2`（500 ms）、`sub008-C9`（520 ms）以及 `sub003-B11`（640 ms），显示色彩信息在腹侧通路中向高级语义与短时维持阶段的延续。
2. **各几何形状内解码的高一致性**：
   - 在上述核心位点中，三个形状单条曲线的峰值解码准确率高度一致（如 `sub007-H5` 在三种形状下分别为 69.9%、68.3%、70.1%），说明这些通道所提取的纯色彩模式对几何边界具有极强的几何几何不变性（Shape Invariance）。
