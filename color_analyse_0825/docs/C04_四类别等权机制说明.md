## 1. 对应源码与执行流程

在 `C04_screen_color_channels_0825.m` 中，计算核心主时间窗 $[100, 400]\text{ ms}$ 内色彩效应的代码如下：

```matlab
% 计算各类别在主窗内的配对差值
cat_diffs = zeros(1, 4);
all_c_vals = [];
all_g_vals = [];

for c = 1:4
    % 提取第 c 个类别所有配对试次在时间窗内的均值
    c_trials = mean(ch_epoch(col_pair_idx{c}, win_mask), 2);
    g_trials = mean(ch_epoch(gry_pair_idx{c}, win_mask), 2);
    
    % 步骤 1：先在各类别内部求“彩色 - 灰度”的平均配对差值
    cat_diffs(c) = mean(c_trials - g_trials, 'omitnan');
    
    all_c_vals = [all_c_vals; c_trials];
    all_g_vals = [all_g_vals; g_trials];
end

% 步骤 2：对 4 个类别的差异求算术平均（即四类别等权色彩效应）
gen_eff = mean(cat_diffs);
```

## 2. 数学公式与等权机制推导

### 2.1 步骤 1：类别内部同图配对差异（一阶平均）

实验中包含四大语义类别（$c = 1, 2, 3, 4$）：
1. **Face**（人脸，Trigger: 彩 11，灰 12）
2. **Object**（物体，Trigger: 彩 21，灰 22）
3. **Body**（身体，Trigger: 彩 31，灰 32）
4. **Place**（场景，Trigger: 彩 41，灰 42）

设第 $c$ 个类别经过同图匹配后共有 $N_c$ 对有效的配对试次。对其中的第 $i$ 对图片（同一张图片），其彩色刺激响应为 $x_{c, i}^{\text{col}}$，灰度刺激响应为 $x_{c, i}^{\text{gry}}$。

循环内部的 `cat_diffs(c)` 计算的是**类别 $c$ 内部的平均色彩差值**：

$$\overline{\Delta}_c = \frac{1}{N_c} \sum_{i=1}^{N_c} \left( x_{c, i}^{\text{col}} - x_{c, i}^{\text{gry}} \right)$$

这一步消除了各类别内部每张图片自身的形状、轮廓和语义基线差异。

---

### 2.2 步骤 2：跨类别算术平均（二阶平均，即“等权”）

循环外部的 `gen_eff = mean(cat_diffs)` 对上述 4 个类别的差异均值求无权重的算术平均：

$$\text{gen\_eff} = \frac{1}{4} \sum_{c=1}^4 \overline{\Delta}_c = \frac{1}{4} \overline{\Delta}_{\text{Face}} + \frac{1}{4} \overline{\Delta}_{\text{Object}} + \frac{1}{4} \overline{\Delta}_{\text{Body}} + \frac{1}{4} \overline{\Delta}_{\text{Place}}$$

展开为显式权重形式：

$$\text{gen\_eff} = 0.25 \times \overline{\Delta}_{\text{Face}} + 0.25 \times \overline{\Delta}_{\text{Object}} + 0.25 \times \overline{\Delta}_{\text{Body}} + 0.25 \times \overline{\Delta}_{\text{Place}}$$

每个类别的权重恒定为 $\frac{1}{4} = 25\%$。这就是所谓的**四类别等权（Equal Weighting / Macro-average）**。

## 3. 为什么不直接将所有试次合在一起求平均？（等权 vs 不等权对比）

为了更清楚地理解“等权”的作用，我们将它与**直接池化平均（Micro-average）**进行对比：

| 计算方式 | 数学形式 | 各类别权重 $w_c$ | 潜在问题 / 优势 |
| :--- | :--- | :--- | :--- |
| **等权宏平均 (当前做法)**<br>`mean(cat_diffs)` | $\text{gen\_eff} = \sum_{c=1}^4 \frac{1}{4} \overline{\Delta}_c$ | **恒为 $25\%$** | 无论各类别因坏试次剔除后剩余多少对，各大类对总体效应的贡献严格对等。 |
| **试次直接池化 (不等权微平均)**<br>`mean(all_c - all_g)` | $\overline{\Delta}_{\text{pooled}} = \sum_{c=1}^4 \left( \frac{N_c}{N_{\text{total}}} \right) \overline{\Delta}_c$ | **$w_c = \frac{N_c}{N_{\text{total}}}$**（取决于试次数） | 若某类别因伪迹剔除丢失较多试次，其发言权被削弱；试次多的类别会主导检验结果。 |

### 实际数据场景举例：
在实际记录中，由于伪迹剔除或触发丢失，不同被试的各类有效配对数会有轻微不对称。例如：
- **sub005** 的有效配对数是 $[70, 70, 69, 70]$（Body 类少 1 对）；
- **sub007** 的有效配对数是 $[64, 64, 63, 64]$。

通过“先求各类别内部均值 $\overline{\Delta}_c$，再求类别间平均”，从数学上严格锁定了每个类别的权重比为 $1:1:1:1$。

## 4. 神经科学与统计设计意义

1. **排除“特定类别色彩偏好”（Category Bias）主导假象**：
   - 某些腹侧枕颞叶电极可能表现出强烈的“人脸特异性”或“场景特异性”。
   - 如果不按类别等权控制，一旦电极在某一个优势类别上有巨大响应波动，就可能掩盖或扭曲其他类别的表现。
   - 等权设计迫使检验指标必须综合平衡 4 种不同视觉语义背景下的色彩差异。

2. **自然衔接后续“方向一致性（Concordance）”判定**：
   - `cat_diffs` 作为一个长度为 4 的向量被完整保留下来，紧随其后在代码第 139–145 行用于判定该电极是否在**所有类别**上均表现出一致的正向增强或负向抑制：
     ```matlab
     if all(cat_diffs > 0)
         concord_type = 'Concordant_Positive';  % 四类别全部同向增强
     elseif all(cat_diffs < 0)
         concord_type = 'Concordant_Negative';  % 四类别全部同向抑制
     else
         concord_type = 'Category_Biased';      % 方向不一致，存在类别偏好
     end
     ```
   - 只有当 `cat_diffs` 独立计算时，才能精确量化电极是“真正通用的色彩敏感”还是“仅对特定类别敏感”。

## 5. 总结

`gen_eff = mean(cat_diffs)` 的等权机制核心为：
1. **第一层（Within-Category）**：在类别内利用配对试次消除图片语义与形状背景，得到该类别的平均色彩效应 $\overline{\Delta}_c$。
2. **第二层（Across-Category）**：对 4 个类别的 $\overline{\Delta}_c$ 赋予完全相等的权重（各 $25\%$）取算术平均，得到无类别偏倚的全局色彩效应指标 $\text{gen\_eff}$。
