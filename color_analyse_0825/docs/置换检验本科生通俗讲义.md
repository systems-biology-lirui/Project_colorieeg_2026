# 配对符号翻转置换检验——本科生通俗讲义

> **一句话大白话**：  
> **置换检验根本不是什么高深魔法，它就是让电脑“疯狂抛硬币 2000 次”，看看在假设“颜色完全没用”的纯噪声情况下，光凭运气能不能碰出你实测的数据！**

---

## 1. 场景与问题：你和导师的对话

假设你是一名正在做脑电实验的本科生。  
你在病人的大脑视觉皮层植入了一根电极，你想证明：**这个电极看“彩色”比看“灰度”反应更强！**

实验中，为了公平，每张图片都有**彩色版**和**灰度版**。  
为了让你彻底看懂，我们先别看 280 张图，**假设整个实验我们只看了 3 张图片**：
- 图片 1：苹果
- 图片 2：香蕉
- 图片 3：人脸

---

## 2. 第一步：算出现实的“真实成绩单”

实验做完了，你的电极记录到了 3 张图片在脑子里的反应能量：

| 图片编号与名称 | 彩色版能量 ($x_{\text{col}}$) | 灰度版能量 ($x_{\text{gry}}$) | 彩色减灰度的配对差值 ($d = x_{\text{col}} - x_{\text{gry}}$) |
| :--- | :---: | :---: | :---: |
| 图片 1（苹果） | 10 | 7 | **+3** |
| 图片 2（香蕉） | 8 | 6 | **+2** |
| 图片 3（人脸） | 9 | 5 | **+4** |

算算这 3 张图片的平均色彩效应：
$$\text{真实平均差值} = \frac{3 + 2 + 4}{3} = +3.0$$

你兴奋地跑去跟导师汇报：“老师！看彩色比看灰度平均高了 **+3.0**，这个电极绝对是对颜色敏感的脑区！”

导师推了推眼镜，问了你一个灵魂问题：
> **“小同学，你怎么知道这个 +3.0 是大脑真的对颜色有反应，还是病人刚好眨了眨眼、纯属脑电背景随机噪声凑巧碰出来的？”**

---

## 3. 第二步：导师的质疑（统计学上的“零假设”）

导师的逻辑是这样的：
1. **假装颜色根本没用**：假设这个电极对颜色一视同仁，彩色灰度在它眼里都是浮云。
2. **那为什么苹果的彩色测出来是 10、灰度是 7 呢？**  
   导师说：纯属巧合！可能是测彩色那一瞬间病人精神好一点，测灰度时走了下神。
3. **关键推论（抛硬币原理）**：  
   如果颜色真的不起作用，那我们如果把时间倒流再测一次：
   - 苹果测出来“彩色是 7、灰度是 10”的概率，跟“彩色是 10、灰度是 7”是**完全一样大**的！
   - 如果彩色是 7、灰度是 10，那么它的差值不就从 **+3** 变成了 **-3** 吗？
4. **结论**：  
   **如果颜色没用，那么每张图片算出来的差值，前面冠以“+ 号”还是“- 号”，就像抛硬币一样，完全是五五开（各有 50% 几率）！**

---

## 4. 第三步：让电脑“抛硬币 2000 次”（模拟纯噪声世界）

既然导师怀疑这只是运气，那我们就在电脑里做实验：  
**让电脑假装颜色没用，纯靠抛硬币（随机给每张图分配 +1 或 -1），看看瞎蒙能蒙出多大的平均值！**

我们手里的真实差值是：`[+3, +2, +4]`。

### 模拟第 1 次（电脑掷硬币结果：反面、正面、反面 $\rightarrow -1, +1, -1$）：
- 苹果强行变号：$-3$
- 香蕉保持原号：$+2$
- 人脸强行变号：$-4$
- 电脑这次瞎蒙出来的平均值：
  $$\text{假平均值}_1 = \frac{-3 + 2 - 4}{3} = -1.67$$

### 模拟第 2 次（电脑掷硬币结果：正面、反面、正面 $\rightarrow +1, -1, +1$）：
- 苹果：$+3$
- 香蕉：$-2$
- 人脸：$+4$
- 电脑这次瞎蒙出来的平均值：
  $$\text{假平均值}_2 = \frac{+3 - 2 + 4}{3} = +1.67$$

### 模拟第 3 次（电脑掷硬币结果：反面、反面、反面 $\rightarrow -1, -1, -1$）：
- 苹果：$-3$
- 香蕉：$-2$
- 人脸：$-4$
- 电脑这次瞎蒙出来的平均值：
  $$\text{假平均值}_3 = \frac{-3 - 2 - 4}{3} = -3.0$$

……  
电脑不知疲倦地这样**抛硬币模拟了 2000 次**！  
每次模拟，电脑都把这 3 张图（在真实实验中是 280 张图）随机变号，然后求个平均值。

最终，电脑手里有了 **2000 个纯靠瞎蒙产生的“假平均值”**。  
这 2000 个数大部分都在 0 附近晃悠（比如 $+0.1, -0.2, +0.05$），偶尔运气好会有稍大的数。

---

## 5. 第四步：数一数，见证奇迹（计算 $p$ 值）

现在你把真实的成绩单拿出来：你实测的真实平均值是 **$+3.0$**。

你去问电脑这 2000 个瞎蒙的假平均值：  
**“在这 2000 次瞎蒙里，有多少次仅凭抛硬币的运气，就能搞出一个绝对值大于或等于 3.0 的极端数值？”**

### 结果分析：
- **如果电脑回答**：  
  “我查了一下，2000 次瞎蒙里，只有 **1 次** 偶然达到了 3.1，其他 1999 次全都在 0 附近打转！”  
  - 算算概率（$p$ 值）：
    $$p = \frac{1 + 1}{2000 + 1} = \frac{2}{2001} \approx 0.001$$
  - **人话翻译**：靠纯噪声撞出你这个结果的概率只有 **千分之一**！  
    此时你就可以挺起胸膛跟导师说：“老师，纯靠运气撞出这个效应的几率不到 0.1%，这绝不是噪声，这个电极是真的对颜色起反应！”（**统计显著！**）

- **反之，如果电脑回答**：  
  “我查了一下，2000 次瞎蒙里，足足有 **600 次** 都大于或等于 3.0 呢！”  
  - 算算概率（$p$ 值）：
    $$p = \frac{600 + 1}{2000 + 1} \approx 0.30$$
  - **人话翻译**：电脑闭着眼睛扔硬币都有 30% 的概率拿到 3.0。你这个 3.0 根本不算啥稀奇东西，纯属噪声！（**不显著！**）

## 6. 代码逐行映射：你写的那 5 行 MATLAB 到底在干啥？

回到你的代码 [C04_screen_color_channels_0825.m](file:///e:/liulab_project/Project_colorieeg_2026/color_analyse_0825/matlab/C04_screen_color_channels_0825.m#L128-L136)：

```matlab
% 1. 拿到全实验 280 张图片的真实差值 (就像上面的 [+3, +2, +4, ...])
paired_diffs = all_c_vals - all_g_vals;
n_pairs = numel(paired_diffs);

% 2. 电脑一次性抛 2000 次硬币！
% 生成一个 280 行 x 2000 列的矩阵，每一列代表一次虚拟实验，里面全由 +1 和 -1 组成
signs = (rand(n_pairs, cfg.n_perm) > 0.5) * 2 - 1;

% 3. 把 280 张图的真实差值和硬币的正负号相乘，求平均值！
% 得到 2000 次瞎蒙模拟出来的假平均值向量 (1 行 x 2000 列)
perm_diffs = mean(paired_diffs .* signs, 1);

% 4. 统计 2000 次瞎蒙里，有多少次绝对值 >= 真实平均值 (gen_eff)，算 p 值
p_perm = (sum(abs(perm_diffs) >= abs(gen_eff)) + 1) / (cfg.n_perm + 1);
```

### 细节点拨：为什么末尾要 `+ 1` 和 `/ (cfg.n_perm + 1)`？
- **分子 `+1`**：把你真实测到的这一次实验，也算作一种合法的排列情况（真实测到的绝对值显然 $\ge$ 真实测到的绝对值，所以必然有 1 次）。
- **分母 `+1`**：总次数从 2000 变成 $2000 + 1 = 2001$。
- **作用**：防止当 2000 次置换中一次都没超过实测值时，算出 $p = 0 / 2000 = 0$ 的数学谬误。在概率学上，$p$ 值永远不可能绝对等于 0，最小极限是 $\frac{1}{2001} \approx 0.0005$。

---

## 7. 一句话总结记住它

> **置换检验的精髓只有两步：**  
> 1. **在零假设下把“正负号当硬币抛”，用电脑模拟出 2000 次纯噪声的假平均值；**  
> 2. **看看你的真实平均值在 2000 个假平均值里有多“罕见”，算出超越它的几率（就是 $p$ 值）！**
