## 5. C00/C01：连续数据与唯一预处理

### 5.1 不把 Session 拼接当作真实连续

每个原始 Session 至少保留 `session_id`、`segment_id`、原始文件、原始 fs、样本数和事件。一个 Session 若有真实记录断点，应进一步分段。

可保留拼接文件作为兼容存储，但必须另存 segment_table：每段原始起止点、目标采样率起止点、来源、边界原因。计算必须逐段取出进行，不跨边界 resample、filtfilt 或 Hilbert。

不能仅从行为 Session 起始 trigger 反推原始采集拼接边界。应优先从 C00 原始文件和分段长度恢复；没有可靠来源时将该输入标为不可用于合规连续提取，不能猜测边界。

### 5.2 预处理步骤

对每个真实连续段执行：

1. 核对二维信号、通道标签、实际 fs、单位；拒绝未解释的 NaN/Inf。
2. 对每个通道减去该段中位数。
3. 重采样到 500 Hz，按段局部坐标转换事件：`round((sample_raw-1)*500/fs_raw)+1`。
4. 0.1–200 Hz 四阶 Butterworth 零相位带通，使用数值稳定的 SOS 表示。
5. 50/100/150 Hz、Q=30 零相位陷波。
6. 读取唯一人工通道决定表，建立严格同杆直接相邻三联表。
7. 连续 Laplacian：`center - (left + right)/2`。
8. 保存连续信号及元数据；ERP epoch 是独立可选产物。

这里只恢复历史预处理要求，不宣称其优于当前 Q=35 路线。实际数据质量需验收。若改用当前 C06 的预处理方式，应明确作为另一个 signal_variant，不可沿用相同缓存键。

### 5.3 通道与定位规则

- 人工坏道表只选一个权威输入路径，保存文件身份；两个候选文件同时存在时不能静默优先其中一个。
- 依据已有要求，空白决定保留，明确 exclude 排除；`bad` 等别名需要显式映射，未知值报错。
- 三个成员均存在、同杆、编号直接相邻、均未被排除；禁止以远端邻居替换坏道。
- 无法解析、归一化后重名、通道不唯一均记录/中止，不能取第一个命中。
- 定位缺失不能用“非 VOTC”替代；保存 `localization_status=missing`。若研究决定必须有定位才纳入，则在主分析前锁定该规则。
- SOZ/IED、灰白质、ROI 等条件只可根据实际审核资料实施，不能从缺失资料或名称猜测。明确候选清单应在查看本次效应之前冻结。
- 原始输入和人工表变更后，缓存必须失效。

C02 与 trigger QC 共享同一匹配表。以 Session 为单位先核对精确 trigger 序列，再结合时序审计定位丢码和错配。LCS 可作为候选对齐方法，但重复 trigger 下可能有多个等长解；出现歧义时标记 `ambiguous`，不能仅用对齐率认定唯一正确。

## 7. C06：唯一频段特征提取

### 7.1 精确频段与计算顺序

| 名称 | 子频段 Hz | 分析地位（建议） |
|---|---|---|
| Delta | [1,4] | 探索性 |
| Theta | [4,8] | 主频段 |
| Alpha | [8,12] | 主频段 |
| Beta | [13,30] | 主频段 |
| Low_Gamma | [30,48]、[52,60] | 主频段，子频段等权 |
| High_Gamma | [70,80]、[80,90]、[110,120]、[120,130]、[130,140] | 主频段，五子频段等权 |

实际 High_Gamma 不是连续 70–150 Hz；图注必须给出子频段或明确“70–140 Hz 内五个子频段”。不补入 90–110、140–150 或 Beta/Alpha 间隙。

读取 C01 连续 Laplacian → 各真实连续段逐子频段四阶零相位带通 → Hilbert → 模平方功率 → 提取有效 epoch → 每试次、每子频段归一化 → 子频段等权平均。

滤波器系数固定后在通道外设计；保留实际系数。Hilbert 操作的时间轴必须显式，单通道/单试次情况下不能因 squeeze 改变轴含义。

### 7.2 归一化公式必须锁定

推荐模式 `power_ratio_db`，对于 trial r、子频段 b：

```text
B[r,b] = mean(P[r,b,t], t 属于基线)
Z[r,b,t] = 10*log10(P[r,b,t] / B[r,b])
Feature[r,t] = mean_b(Z[r,b,t])
```

先分别归一化子频段，再等权平均。不得先平均各子频段功率再取 log，除非建立独立的新定义。

当前 C06 模式为 `mean_log_centered_db`：

```text
Z_old[r,b,t] = 10*log10(P[r,b,t])
              - mean_baseline(10*log10(P[r,b,t]))
```

该模式相当于用几何均值作为基线，两者不相等。切换属于科学参数修改，必须新 run。新模式不要求“基线 dB 时间均值严格为 0”；图注应改为“相对试次基线功率的 dB”。旧模式也只是基线窗口均值为 0，不是每个基线点为 0。

对功率接近零的处理应配置明确的正数 floor、适用单位及命中比例；基线为零、非有限或大面积触及 floor 的数据应标记无效，不能只靠 eps 掩盖。

### 7.3 Epoch 和边界保护

- Epoch 为 [-500,1000) ms：`-500:2:998`，750 点。
- 基线 [-300,-100] 含端点：101 点。
- 主窗 [100,400] 含端点：151 点；[200,500] 同为151点。
- 禁止越界索引夹紧、复制首末点或用零填充后参与统计。
- 必须区分“epoch 落在物理段内”和“epoch 不受段边界滤波影响”；后者还需要保护区。
- 保护区按实际滤波/重采样/Hilbert 处理及容许误差的数值验证确定，并记录每频段时长。短段无法满足要求则明确排除。
- 中间伪影不能简单剪掉后拼接。伪影屏蔽、是否分段、保护时长和 trial 排除范围必须预先配置。
- 不假定连续提取自动消除刺激向基线的零相位泄漏。用实际滤波器进行刺激后合成突发的响应检查，尤其关注低频；不根据显著结果临时调整基线。

### 7.4 缓存和数据契约

推荐每 run/subject/task/band 一个 v7.3 MAT，信号以顶层数值数组保存，元数据单独保存。不要把全部大数组塞进单个嵌套结构后，假定 matfile 能直接局部索引其字段。MATLAB 文档说明 matfile 的部分读取需要受支持的变量类型和索引方式，应在目标 MATLAB 版本验证。[MATLAB matfile 文档](https://www.mathworks.com/help/matlab/ref/matlab.io.matfile.html)

```text
feature_db_ntrial_x_nchannel_x_ntime       single
valid_ntrial_x_nchannel                  logical
time_ms_1_x_ntime                        double
baseline_power_ntrial_x_nchannel_x_nsubband
metadata                                配置、trial/channel 表引用、版本、状态
```

valid 的策略要说明是否频段特异。建议主五频段使用预先定义的共同有效 trial/pair 集，避免频段比较受纳入集合差异影响；Delta 可独立有效集。此选择会影响纳入数，必须在运行配置锁定。

至少保存子频段基线功率与归一化前基线统计，供 QC 使用；单靠归一化后特征不能检验基线绝对功率差异。若未来要不重提取就更改任意基线窗口，需另存子频段未归一化 epoch 功率，这是额外磁盘开销，不应默认无限保存全部中间副本。

连续信号、特征、统计分别拥有独立 fingerprint：只改主统计窗口不能使 C01/C06 重跑；改频段/基线不能复用不匹配的特征；改人工坏道或预处理则需刷新上游缓存。

## 8. C07：正确图片配对和统计

### 8.1 图片与重复呈现

基本独立单位是图片身份，不是单次呈现。对每个电极、频段和窗口：

1. 每试次先计算窗口内特征均值。
2. 在相同 Session、类别、图片身份、Color/Gray 条件内汇总所有合格重复。
3. 建议只使用该图片在同一 Session 内两条件均有效的 Session，形成 Session 内差值。
4. 将同一图片各有效 Session 差值等权平均，得到一个图片差值 d[c,i]。
5. 同一图片重复出现不能产生多个独立 sign-flip 单位。

步骤3是对原新方案缺失 Session 情形的明确化建议；避免 Color 来自 Session1、Gray 仅来自 Session2。若采用条件分别跨 Session 汇总，要另行固定规则，不能自动互相回退。

```text
A[c,i,s,k] = mean_repetition(window_mean_feature)
d[c,i] = mean_valid_session(A[c,i,s,Color] - A[c,i,s,Gray])
Delta[c] = mean_image(d[c,i])
G = (Delta[Face]+Delta[Object]+Delta[Body]+Delta[Place])/4
```

保存 pair table：所有贡献的 trial_uid、Session、重复数、图片键、各层权重、无效原因。四类别有任一无有效图片时，不计算“四类别总体”结果；不能 omitnan 后变成三类平均。每类最少图片数应依据实验设计冻结，不能根据结果修改。

### 8.2 置换定义

建议以 G 本身作为统计量，与当前 C07 类别等权框架衔接，避免 C04 混合两种加权。每次对图片差值乘 +1/-1，重新按相同类别权重计算 G_perm；双侧 p 使用：

```text
p_raw = (1 + count(abs(G_perm) >= abs(G_observed))) / (B + 1)
```

该检验需要图片差值层面的交换/对称假设；若不成立，不能宣称对任意分布都有效。同一被试同一图片跨通道和频段共用翻转符号；同图的重复和 Session 不独立翻转。图片排序、随机种子和随机算法固定；跨被试随机流以稳定 subject 身份生成，不由循环位置决定。

置换矩阵分块处理，统计 exceedance 次数即可，不必保存所有通道×时间×置换结果。全零差值应得到 p=1；空集合、缺类别和非有限差值应返回明确不可检验状态。

### 8.3 多重比较与置换分辨率

建议 family 为本次预先纳入全部被试合格电极 × 五主频段的主窗口总体效应。先收齐全部 p，再一次性 Holm，不能每被试或每频段各校正后称为同一全局 family。Holm 控制家族错误率，不要求测试彼此独立；它与 BH/FDR 控制的目标不同。[R stats 多重比较文档](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/p.adjust.html)

排序后的计算定义：`p_adj_sorted(k)=min(1,max_{j<=k}((m-j+1)*p_sorted(j)))`，然后映射回原始行序。无法估计的预定测试保留状态，并用保守 p=1 参与 family 计数；不能看完结果后删除以缩小 m。

当前2000次置换最小 Monte Carlo p约0.0005；10,000次也不必然足够。若 m=3000，Holm 首阈值为0.05/3000≈0.0000167，10,000次的最小 p≈0.0001 无法跨过第一门槛。

因此“10,000次”仅为旧建议，不作为无条件固定上限。运行前根据冻结的 m 规划 B，至少确保 `1/(B+1) < alpha/m`，并留出精度余量、报告 Monte Carlo 不确定性。不能因算力不足退回 raw p，也不能看到结果接近阈值才无规则加置换。若精确枚举可行，可预先选择；若要换 max-T，应作为另一个统计方案单独锁定。

Delta 不扩充主五频段名单；若报告其显著性，单独明确探索性 family。敏感性窗口也单独标记，不与主结果取并集。若希望一次统一控制主效应、conjunction及时间分析全部主张，需要另行规划整体错误率，而不能把每个 family 的0.05说成全项目0.05。

### 8.4 结果命名

| 标签 | 条件 | 含义 |
|---|---|---|
| Overall_Color_Effect | 主窗 p_holm<0.05 | 总体颜色差异 |
| Concordant_Positive | 上述成立且四个 Delta>0 | 总体显著，四类别点估计均正 |
| Concordant_Negative | 上述成立且四个 Delta<0 | 总体显著，四类别点估计均负 |
| Mixed_Direction | 总体显著但点估计不全同号 | 方向混合；不直接声称类别交互显著 |
| Not_Significant | 有效检验未通过校正 | 不等于证明没有效应 |
| Not_Estimable | 缺类别/少配对/数据无效 | 不得与不显著混为一类 |

点估计同号不是“四类均显著”，也不是对新图片独立泛化的证明。若增加四类共同效应检验，应单独实现 conjunction，不以平均检验替代。[Nichols 等，2005](https://www.fil.ion.ucl.ac.uk/spm/doc/papers/NicholsBrett.pdf)

可选的方向性 conjunction 方案：分别得到四类别正向/负向单侧 p，方向内取四者最大值，两个方向合并为 `min(1,2*min(p_conj_pos,p_conj_neg))`，再在预定 conjunction family 内校正。该部分不是修复 C07 主效应的必需前置条件，未实现时必须写“未执行”，不能填一个看似有效的结论。

### 8.5 统计输出最低字段

subject/task/channel/band、signal_variant、run_id、family_id/family_size、窗口、四类图片数与Session覆盖、四类Delta、G、p_raw、p_holm、B、主显著性、方向标签、纳入/失败状态、通道三联成员、解剖及定位状态、pair表路径和输入特征fingerprint。

保留全部候选空间的结果，不只导出显著电极。被试是群体推断层面的独立单位；本阶段电极结果表不构成群体水平被试推断。

## 9. 绘图和基线 QC

### 9.1 绘图与统计同源

主 Color、Gray 曲线按与 C07 一样的图片、Session、类别权重构造；Delta(t) 为同一图片层级差值的类别等权曲线。各类别曲线也使用同一配对集。

验收必须满足：主差值曲线在主窗的均值等于 CSV 的 G（在浮点容差内）。不得用“全试次普通均值”曲线标题显示另一个加权统计量。普通试次平均可作为额外描述图，但标明用途。

误差带以图片为单位估计，不把重复呈现作为独立样本；若用 bootstrap，按类别内图片重采样，同图两条件/Session/时间轴保持关联。保存 seed、次数和区间定义，注明点态区间不是全时程同时显著性。若尚未选择区间方案，先画均值和样本数，不生成含义不清的 SEM。

图注注明真实频段、归一化模式、主窗、各类别图片数、总体校正 p 和方向标签。不要标出未经时间检验的“显著时间段”。同一数据筛选后展示的图应标为选择后描述，不作为独立验证。

批量图按被试和频段分组，缓存只加载一次；解剖表也只读一次。缺定位显示缺失状态，不能因为缺定位阻止信号质检图，也不能自动改变纳入策略。

### 9.2 基线检查

必须基于连续提取后、归一化前的功率，至少覆盖各被试各频段，而不是只检查 test001 的70–90 Hz。

- Color/Gray 基线差异：使用配对图片层级，报告效应量及不确定性，不能用 p>0.05 比例证明基线相等。
- 前序试次：依据同连续段内真实前序事件，包括 catch 和后来被排除的事件；不能直接对筛选后的 trial 表平移一行。
- 漂移：实现实际斜率/分箱描述；当前脚本注释提到第三项，但没有完成对应计算。
- 泄漏：用实际滤波器对刺激后合成信号检查刺激前响应；记录容差、保护区和最不利频段。
- 边界：检查相邻连续段改变时，本段特征不会变化。

若 QC 表明预设基线不适合某频段，报告受影响范围；更换窗口、滤波器或降为探索性均需新配置，不以获得显著结果为目标调参。

### 必须覆盖的验证案例

| 测试 | 验收要求 |
|---|---|
| 打乱Color/Gray试次顺序 | 正确图片配对后的G及固定随机种子的p不变 |
| 同图不同重复数 | 按重复、Session、图片层级的手算结果一致 |
| 图片尾号跨类别重复 | 不发生跨类别误配 |
| 某Session单条件缺失 | 执行明确缺失策略，不能跨Session伪配对 |
| 某类别缺失 | 返回Not_Estimable，不转成三类总体 |
| 全零差值/全常数 | 无除零，零效应p=1 |
| 类别图片数不等 | 主窗、敏感性及每次置换均类别等权 |
| Segment连接处突变 | 后一段改变不影响前一段结果 |
| Epoch越界或保护区不足 | 标记无效，不夹紧、不补零 |
| 实际fs与1000不一致 | 使用真实fs或明确拒绝，不静默错位 |
| 通道缺失/重复命名 | 中止或显式无效，不能输出零通道 |
| 基线公式 | 用手算正功率例子验证两种模式及子频段平均顺序 |
| Holm排序与还原 | 与已知小数组手算值一致；包括并列p和p=1 |
| 置换精度规划 | 在运行前确认family大小与B兼容 |
| 图表同源 | Delta曲线主窗均值与CSV的G一致 |
| 缓存复用 | 只改统计窗口不触发信号提取；改频段使C06缓存失效 |
| 未完成文件 | 下游拒绝读取缺completed或不匹配schema的产物 |
| 单trial/单channel shape | 明确维度且可检测统计不可估计状态 |

数值容差写入验证配置：double手算用严格容差，single缓存往返采用适合信号量级的绝对/相对容差；不能在失败后无解释放宽。可以用少量合成数据做回归测试；真实新分析只在配置明确后执行。
