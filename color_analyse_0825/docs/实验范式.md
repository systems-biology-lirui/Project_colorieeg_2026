**一、实验范式**

本课题使用颅内脑电（SEEG）研究物体典型颜色知识及其与实际颜色感知的关系。“记忆颜色”指物体的长期典型颜色知识，而非实验中要求被试短时维持的颜色。

| 任务 | 刺激与条件 | 研究用途 |
|---|---|---|
| Task1 | 人脸、物体、身体、场景四类别，各包含彩色和灰度版本 | 识别对彩色与灰度存在总体响应差异的电极及频段 |
| Task2 | 白菜、猕猴桃、草莓、西瓜，各包含典型配色（True）、非典型配色（False）、灰度（Gray）版本 | 研究物体典型颜色、实际呈现颜色及二者一致性与神经响应的关系 |
| Task3 | 红、黄、蓝、绿及黑、白色块条件 | 测量实际颜色刺激的神经响应，作为感知颜色表征的参照 |

Task2中，白菜、猕猴桃被标记为绿色记忆类别，草莓、西瓜被标记为红色记忆类别。False条件的具体物理颜色仍需依据实际刺激确认，不能仅根据条件名称推断。

任务以被动观看为主，刺激呈现300 ms，空白期按配置在900–1200 ms之间变化，并设置catch试次监测注意和反应。配置中，Task1每条件35张、Task2每条件20张、Task3每条件30张；这些是配置数量，不等于最终有效试次数。

**二、当前正在使用的预处理与特征提取**

核心改变是：**先在连续信号上提取频段功率，再按刺激事件切分epoch。**

当前Task2代码中的实际顺序为：

1. 读取连续SEEG信号、采集事件和行为记录，建立物体类别、True/False/Gray、记忆颜色及图片身份标签。
2. 每个通道减去连续信号的中位数，去除固定偏置。
3. 根据人工坏道记录建立严格同杆、直接相邻的Laplacian三联通道：中心触点减去左右邻居的均值。
4. 将连续Laplacian信号由1000 Hz重采样至500 Hz。
5. 进行四阶Butterworth、零相位0.1–200 Hz带通，以及50/100/150 Hz、Q=30陷波。
6. 在连续信号上分别进行频段滤波，通过Hilbert解析信号的模平方得到瞬时功率。
7. 将功率转换为对数功率；包含多个子频段时，对子频段的对数功率等权平均。
8. 按事件切分为−500至1000 ms、不含1000 ms的epoch，共750点。
9. 每trial减去−300至−100 ms基线窗口内的平均对数功率，保存多频段特征供后续分析。

频段定义为：

| 频段 | 实际范围（Hz） |
|---|---|
| Delta | 1–4 |
| Theta | 4–8 |
| Alpha | 8–12 |
| Beta | 13–30 |
| Low Gamma | 30–48、52–60 |
| High Gamma | 70–80、80–90、110–120、120–130、130–140 |

这里的基线操作准确地说是**对数功率减去基线对数功率均值**，不是“功率除以基线算术平均功率后取对数”。

另外，当前Task1频段提取脚本仍采用原采样率下Q=35陷波，再进行Laplacian、重采样和分频段提取；它与上述Task2实现尚有差异，因此不能将两者描述为完全一致的预处理流程。

在此基础上，你已经获得一组在不同频段存在Task1总体颜色效应的电极。这些首先是**彩色/灰度响应差异位点**，尚不能直接称为记忆颜色选择性位点。

**三、你提出的研究问题**

1. **灰度水果解码中的类别混淆**

   将两种典型红色物体与两种典型绿色物体进行二分类，解码成功可能反映物体类别或相关视觉、语义属性，而不一定反映记忆颜色。

   跨水果类别训练和测试可以减少对训练类别身份的依赖，但仍可能利用不同类别之间恰好与颜色分组一致的共有属性。因此，需要明确：跨类别泛化在多大程度上能够支持记忆颜色解释。

2. **以同记忆颜色的响应一致性筛选候选电极**

   你的设想是：比较不同物体之间的神经响应，寻找“同记忆颜色、不同物体类别之间的相似性，高于不同记忆颜色之间相似性”的电极。

   这些电极可先定义为具有**记忆颜色分组相关响应结构的候选位点**。待解决的问题是：这种结构是否仍可能由物体类别共有属性造成，以及如何精确定义响应“一致性”。

3. **用纯色色块检验候选位点的颜色对应关系**

   在上述候选电极上，用纯色色块训练分类器，再测试灰度物体，考察灰度物体响应是否对应其典型颜色的感知模式。

   这一检验针对的是**记忆颜色与感知颜色是否存在可迁移的编码关系**。同时需要区分候选筛选数据与验证数据，避免同一灰度数据同时参与选择和验证。

4. **共享表征并非记忆颜色存在的必要条件**

   你进一步质疑：记忆颜色与感知颜色可能出现在不同位点、不同时间、不同频段，或采用无法直接互相解码的模式。

   因此，“是否存在记忆颜色相关信息”与“是否共享感知颜色编码”应当分开。跨解码失败不能单独否定记忆颜色表征，也不能单独证明两者必然采用不同编码。

5. **用多标签建模描述多个因素**

   你的新设想是为每张图片同时标记物体类别、图片身份、记忆颜色、实际呈现颜色、True/False/Gray及颜色一致性，以建模方式研究这些属性与神经响应的关系。

   这里需要解决的核心问题是**因素能否被当前设计独立区分**：典型颜色由物体类别决定；如果False为红绿互换，一致性又由典型颜色和实际颜色共同决定。增加标签可以明确问题，但不能自动消除这些因素之间的依赖。此外，实际呈现颜色与被试主观感知颜色应分开命名，后者需要行为测量支持。
