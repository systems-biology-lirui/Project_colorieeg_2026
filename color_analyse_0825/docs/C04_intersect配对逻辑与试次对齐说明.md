# C04 配对逻辑与试次对齐机制解析

本文档针对 `C04_screen_color_channels_0825.m` 中关键代码：
```matlab
[~, ic, ig] = intersect(trial_info.pic_id(tc), trial_info.pic_id(tg));
col_pair_idx{c} = tc(ic);
gry_pair_idx{c} = tg(ig);
```
详细阐述其科学设计背景、数学与代码逻辑，以及对各被试试次缺失情况的处理机制。

---

## 1. 为什么必须存在这一段代码？（核心必要性）

### (1) 科学层面：严格的“同图配对”（Within-Image Pairing）
* **实验设计初衷**：
  Task 1 共包含 4 个大类（人脸 Face、物体 Object、身体 Body、场景 Place）。每个类别名义上有 70 张不同的独立图片，每张图片均有且仅呈现两次：一次为**彩色版**，一次为**灰度版**（名义总试次为 $4 \times 70 \times 2 = 560$）。
* **消除低层视觉特征与语义混淆**：
  研究目的是筛选“纯粹响应颜色”的电极，必须排除图片的轮廓、纹理、空间频率及语义信息（例如“苹果”与“人脸”本身的脑电响应差异）。
  因此，科学上必须对**完全相同的一张图片**计算其彩色与灰度响应的成对差值：
  $$\Delta \text{Power}_i = \text{Power}(\text{Color}_i) - \text{Power}(\text{Gray}_i)$$
  其中 $i$ 表示特定的同一张图片（Same `pic_id`）。
* **随机播放顺序的对齐**：
  在实验中，刺激是以伪随机顺序逐一呈现的。第 1 个彩色试次呈现的可能是“图片 15（自行车）”，而第 1 个灰度试次呈现的可能是“图片 3（人脸）”。
  若不按 `pic_id` 查找对应关系，直接按试次顺序相减，就会出现“彩色自行车 减 灰度人脸”，完全破坏了实验配对控制。

### (2) 程序健壮性层面：自动过滤“孤儿试次”并保证维度匹配
* 在实际脑电采集与预处理过程中，常因硬件触发丢失或伪迹剔除导致少量试次缺失。
* 如果某类别的彩色试次有 70 个，而灰色试次只记录到 69 个，就意味着有 1 张图片只有彩色呈现、没有对应的灰色呈现（孤儿试次）。
* 若不经处理直接做减法，MATLAB 会直接报错：`Matrix dimensions must agree`（矩阵维度不匹配）。
* `intersect` 能够动态找出彩色与灰色中**共同存在的图片编号**，并将没有伙伴的孤儿试次自动丢弃，确保最终提取的两个向量长度绝对相等且严格成对。

## 2. MATLAB `intersect` 在此处的具体工作机制

以某类别 $c$ 为例：
1. `tc = find(trial_info.trigger == cat_trig_col(c));`
   找到属于该类别的所有彩色试次在总试次表中的行号。
2. `tg = find(trial_info.trigger == cat_trig_gry(c));`
   找到属于该类别的所有灰度试次在总试次表中的行号。
3. `[C, ic, ig] = intersect(trial_info.pic_id(tc), trial_info.pic_id(tg));`
   * `trial_info.pic_id(tc)` 是彩色试次对应的图片编号列表（例如 70 个数）。
   * `trial_info.pic_id(tg)` 是灰度试次对应的图片编号列表（例如 69 个数，缺少了编号为 45 的图片）。
   * `C` 是两者的交集，即既有彩色又有灰度的共有图片编号（共 69 个）。
   * `ic` 是交集元素在 `tc` 中的索引位置。
   * `ig` 是交集元素在 `tg` 中的索引位置。
4. `col_pair_idx{c} = tc(ic);`
   `gry_pair_idx{c} = tg(ig);`
   * 经过索引重排后，`col_pair_idx{c}` 与 `gry_pair_idx{c}` 的长度完全相等（均为 69）。
   * 更重要的是，对任意第 $k$ 对，$k \in [1, 69]$：
     $$\text{trial\_info.pic\_id}(\text{col\_pair\_idx}\{c\}(k)) \equiv \text{trial\_info.pic\_id}(\text{gry\_pair\_idx}\{c\}(k))$$
     严格保证第 $k$ 个彩色试次与第 $k$ 个灰色试次是**同一张图片**！编号为 45 的孤儿试次被安全剔除。

## 4. 后续代码如何平滑自适应处理这种非对称？

当类别间的有效配对数不相等时（例如 sub005 的 `[70, 70, 69, 70]`），代码通过以下两步设计保证了逻辑的严密与稳健：

### (1) 类别平衡色彩效应计算（等权均值）
```matlab
for c = 1:4
    c_trials = mean(ch_epoch(col_pair_idx{c}, win_mask), 2);
    g_trials = mean(ch_epoch(gry_pair_idx{c}, win_mask), 2);
    cat_diffs(c) = mean(c_trials - g_trials, 'omitnan');
    all_c_vals = [all_c_vals; c_trials];
    all_g_vals = [all_g_vals; g_trials];
end

% 四类别等权色彩效应
gen_eff = mean(cat_diffs);
```
* 对每个类别 $c$ 分别计算内部均值差 $\overline{\Delta}_c$；
* 最终的通用色彩效应 `gen_eff` 是对 4 个类别的差异取平均：
  $$\text{gen\_eff} = \frac{1}{4} \sum_{c=1}^4 \overline{\Delta}_c$$
  这种**宏平均（Macro-average）**机制确保了 4 个类别的权重完全相等（各占 25%），不会因为某类别有 70 对而另一类别有 69 对导致权重倾斜。

### (2) 置换检验的动态配对数自适应
```matlab
% 配对检验
paired_diffs = all_c_vals - all_g_vals;
n_pairs = numel(paired_diffs);

% 配对符号翻转置换检验
signs = (rand(n_pairs, cfg.n_perm) > 0.5) * 2 - 1;
perm_diffs = mean(paired_diffs .* signs, 1);
```
* `all_c_vals` 与 `all_g_vals` 将 4 个类别的有效配对纵向串联。
  由于在每个类别内部彩色与灰色都是严格一一对应的，串联后的总向量长度自然完全相等（例如 sub001 为 276，sub005 为 279，sub007 为 255）。
* 配对差值 `paired_diffs` 的元素个数直接通过 `n_pairs = numel(paired_diffs)` 动态获取，**绝不硬编码为 280**。
* 置换检验通过为每一个成对差值随机赋予 $+1$ 或 $-1$ 符号翻转完成零假设分布构建，无论总对数是多少均能完美自适应。

## 5. 总结

1. **存在必要**：`intersect` 保证了“同一张图片自己减自己”的严格控制，消除了语义、形状混淆，同时自动剔除硬件丢步导致的单边孤儿试次，避免矩阵维度不一致报错。
2. **非对称处理**：当部分类别存在试次缺失时，`intersect` 动态确定各类别有效配对数。下游算法通过“类别内均值差等权平均”和“动态配对数置换检验”，在数学和统计上均做到了完全自适应。
