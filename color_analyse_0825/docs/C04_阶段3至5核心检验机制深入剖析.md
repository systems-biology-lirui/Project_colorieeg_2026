## 1. 对应代码整体全貌

```matlab
% -------------------------------------------------------------
% 【阶段 2 准备】：计算 4 个类别各自的主窗配对差值
% -------------------------------------------------------------
cat_diffs = zeros(1, 4);
all_c_vals = [];
all_g_vals = [];

for c = 1:4
    % 提取主窗 [100, 400] ms 内各试次的时域均值 (向量长度为 Nc)
    c_trials = mean(ch_epoch(col_pair_idx{c}, win_mask), 2);
    g_trials = mean(ch_epoch(gry_pair_idx{c}, win_mask), 2);
    
    % 类别 c 内的配对差值平均
    cat_diffs(c) = mean(c_trials - g_trials, 'omitnan');
    
    % 纵向拼接全部有效配对供置换检验使用
    all_c_vals = [all_c_vals; c_trials];
    all_g_vals = [all_g_vals; g_trials];
end

% -------------------------------------------------------------
% 【阶段 3】：四类别等权色彩效应 (Macro-Average)
% -------------------------------------------------------------
gen_eff = mean(cat_diffs);

% -------------------------------------------------------------
% 【阶段 4】：非参数配对符号翻转置换检验 (Sign-Flip Permutation)
% -------------------------------------------------------------
paired_diffs = all_c_vals - all_g_vals;  % 全样本配对差值 (长为 N_pairs)
n_pairs = numel(paired_diffs);

% 锁定随机种子保证可重复性
rng(sub_idx * 100 + b);

% 生成随机符号矩阵 (N_pairs 行 x 2000 列, 元素为 +1 或 -1)
signs = (rand(n_pairs, cfg.n_perm) > 0.5) * 2 - 1;

% 模拟 2000 次零假设下的伪均值差
perm_diffs = mean(paired_diffs .* signs, 1);

% 计算双侧经验 p 值 (含连续性校正 +1)
p_perm = (sum(abs(perm_diffs) >= abs(gen_eff)) + 1) / (cfg.n_perm + 1);
sub_raw_pvals(ch) = p_perm;

% -------------------------------------------------------------
% 【阶段 5】：四类别方向一致性判定 (Concordance)
% -------------------------------------------------------------
if all(cat_diffs > 0)
    concord_type = 'Concordant_Positive';   % 四类全正向增强
elseif all(cat_diffs < 0)
    concord_type = 'Concordant_Negative';   % 四类全负向抑制
else
    concord_type = 'Category_Biased';       % 存在类别偏向 (方向不一致)
end
```

## 2. 阶段 3：四类别等权色彩效应计算（宏平均）

### 2.1 数据的两层结构（层次化平均）

很多统计分析容易直接把全部 280 对试次混在一起取平均，但本项目采用了严格的**两层层次化平均（Two-Stage Hierarchical Averaging）**：

```mermaid
graph TD
    subgraph 第一层：类别内部同图配对消歧
        F["人脸 Face (N1 对)"] --> DF["Δ_Face = mean(c - g)"]
        O["物体 Object (N2 对)"] --> DO["Δ_Object = mean(c - g)"]
        B["身体 Body (N3 对)"] --> DB["Δ_Body = mean(c - g)"]
        P["场景 Place (N4 对)"] --> DP["Δ_Place = mean(c - g)"]
    end
    subgraph 第二层：四类别等权平均
        DF --> G["gen_eff = (Δ_Face + Δ_Object + Δ_Body + Δ_Place) / 4"]
        DO --> G
        DB --> G
        DP --> G
    end
```

### 2.2 为什么必须采用“等权”？

1. **抵御不同被试的试次微小不对称**：
   - 实验设计名义上每类各有 70 对图片。
   - 但在真实 sEEG 采集与预处理中，某些被试在个别类别上有坏试次被剔除（例如 sub005 的有效配对数为 `[70, 70, 69, 70]`，sub007 为 `[64, 64, 63, 64]`）。
   - 如果直接把全部试次混在一起求均值（微平均，Micro-average）：
     $$\overline{\Delta}_{\text{pooled}} = \frac{N_1}{N_{\text{total}}} \overline{\Delta}_1 + \frac{N_2}{N_{\text{total}}} \overline{\Delta}_2 + \frac{N_3}{N_{\text{total}}} \overline{\Delta}_3 + \frac{N_4}{N_{\text{total}}} \overline{\Delta}_4$$
     此时各类别权重变成了 $\frac{N_c}{N_{\text{total}}}$，试次数多的类别天然拥有更大发言权。
   - 采用 `gen_eff = mean(cat_diffs)`：
     $$\text{gen\_eff} = \frac{1}{4} \overline{\Delta}_{\text{Face}} + \frac{1}{4} \overline{\Delta}_{\text{Object}} + \frac{1}{4} \overline{\Delta}_{\text{Body}} + \frac{1}{4} \overline{\Delta}_{\text{Place}}$$
     权重固定锁死为**各自严格占 25%**。

2. **科学层面防止“语义类别偏好”主导全局假象**：
   - 在大脑高级视觉皮层（腹侧枕颞叶），许多脑区具有强烈的类别选择性（如梭状回 FFA 强烈偏好人脸，海马旁回 PPA 偏好场景）。
   - 如果某电极正好靠近人脸区，它在人脸上的反应幅度可能极其巨大（例如 $+6\text{ dB}$），而在其他类别上几乎为 $0\text{ dB}$。
   - 等权设计明确了我们的科学目标：我们要寻找的是**对颜色本身具有普遍敏感性（General Color Sensitivity）**的电极，而不是单纯由某单一类别的巨大响应拉动起来的“伪色彩电极”。

## 3. 阶段 4：非参数配对符号翻转置换检验（Sign-Flip Permutation Test）

这是本脚本在统计严谨性上最核心的突破点。

### 3.1 为什么坚决不用常规的“配对 t 检验（paired t-test）”？
- **数据不满足正态分布假定**：脑电频段功率（特别是高频 High Gamma）通常呈现右偏或长尾分布，强行使用要求正态分布的参数检验会虚假抬高假阳性率（Type I error）。
- **非参数置换检验是电生理领域的金标准**：它直接使用当前通道自己测得的真实数据构建零假设分布，不作任何分布先验假设。

---

### 3.2 零假设（$H_0$）的生物物理本质与“符号翻转”逻辑

* **零假设（$H_0$）**：
  > “该通道对刺激颜色**完全不敏感**，记录到的彩色试次能量 $c_i$ 与灰度试次能量 $g_i$ 的差异纯粹是由大脑自发背景噪声或偶然随机波动引起的。”

* **符号翻转（Sign-Flip）原理**：
  - 如果零假设成立，那么在任何一次呈现中，“彩色”和“灰度”这两个标签完全可以互换。
  - 对于第 $i$ 张图片，原本计算的差值为：
    $$d_i = c_i - g_i$$
  - 如果将标签随机互换（把灰度当彩色，把彩色当灰度），差值就会变成：
    $$g_i - c_i = -(c_i - g_i) = -d_i$$
  - 因此，在零假设下，$d_i$ 取正号（$+d_i$）还是负号（$-d_i$），在概率上是严格对称且等可能的（如同抛掷一枚均匀硬币，各占 50%）。

---

### 3.3 矢量化矩阵运算拆解（MATLAB 代码透视）

代码在实现上采用了一步到位的矩阵矢量化加速，效率极高：

#### 第 1 步：配对差值向量
```matlab
paired_diffs = all_c_vals - all_g_vals;
```
- `paired_diffs` 是一个列向量，维度为 $[N_{\text{pairs}} \times 1]$（例如 $276 \times 1$）。
- 里面的每个数字是某张特定图片实测的 $(c_i - g_i)$。

#### 第 2 步：随机符号矩阵生成
```matlab
signs = (rand(n_pairs, cfg.n_perm) > 0.5) * 2 - 1;
```
- `rand(n_pairs, 2000)`：生成一个 $276 \times 2000$ 的均匀随机矩阵（数值在 $(0, 1)$ 之间）。
- `> 0.5`：产生逻辑值 `true` (1) 或 `false` (0)，各占 50% 概率。
- `* 2 - 1`：
  - 若为 1：$1 \times 2 - 1 = +1$
  - 若为 0：$0 \times 2 - 1 = -1$
- 最终得到一个尺寸为 $[276 \times 2000]$ 的符号矩阵 `signs`，每一列代表一次“平行的虚拟置换实验”。

#### 第 3 步：广播点乘与置换伪均值计算
```matlab
perm_diffs = mean(paired_diffs .* signs, 1);
```
- `paired_diffs .* signs`：MATLAB 自动将 $[276 \times 1]$ 与 $[276 \times 2000]$ 广播点乘。
  第 $k$ 列即为第 $k$ 次置换下，每张图片随机乘以 $+1$ 或 $-1$ 后的虚拟差值。
- `mean(..., 1)`：对每列的 276 个数值求均值。
- 得到一个 $[1 \times 2000]$ 的行向量 `perm_diffs`。
  这 2000 个值就是**在“毫无色彩效应”的纯噪声假设下，偶然可能产生的效应量分布（零假设经验分布直方图）**，它以 0 为中心对称分布。

---

### 3.4 经验双侧 $p$ 值的计算与连续性修正

```matlab
p_perm = (sum(abs(perm_diffs) >= abs(gen_eff)) + 1) / (cfg.n_perm + 1);
```

数学公式：

$$p_{\text{perm}} = \frac{\sum_{k=1}^K \mathbb{I}\left( |\text{perm\_diff}_k| \ge |\text{gen\_eff}| \right) + 1}{K + 1}$$

其中：
1. **为什么要取绝对值 `abs`？**
   - 采用**双侧检验（Two-tailed test）**。
   - 我们不仅关注“色彩诱发能量增强”（$\text{gen\_eff} > 0$），也同样关注“色彩诱发能量抑制/去同步化”（$\text{gen\_eff} < 0$，如 Alpha 频段常见的去同步效应）。
   - 只要效应量偏离 0 足够极端，均属于显著。
2. **分子计数部分 $\sum \mathbb{I}(\dots)$**：
   - 统计在 2000 次纯噪声模拟中，有多少次偶然产生了比我们实测的绝对效应量 $|\text{gen\_eff}|$ 还要极端的结果。
   - 如果 2000 次模拟中只有 2 次超过了实测值，说明实测效应发生在噪声中的概率极低（约为千分之一）。
3. **为什么分子分母都要 $+1$？（学术界标准规范）**：
   - 依据著名非参数统计文献 **Phipson & Smyth (2010)**（*Permutation P-values Should Never Be Zero*）：
   - 实测数据本身就是置换空间中的一种合法排列。因此，真实观测值算作分子中的第 1 次超越（分子 $+1$），总排列数也相应加 1（分母 $K+1$）。
   - 这防止了当实测效应极大、置换模拟 0 次超越时产生非法的 $p = 0 / 2000 = 0$ 报错（经验置换的 $p$ 值下限应为 $\frac{1}{2001} \approx 0.0005$）。

## 4. 阶段 5：四类别方向一致性判定（Concordance Categorization）

置换检验通过了（例如 $p_{\text{perm}} < 0.05$），只能说明**总体均值显著不等于 0**。但它不能回答一个关键的神经科学问题：**这个电极是各类别普遍敏感，还是仅仅由某一类别偏好引发的？**

### 4.1 假象剖析：为什么单看 $p$ 值不够？

设想某通道记录到以下四类别的色彩效应差值：
- $\Delta_{\text{Face}} = +5.0\text{ dB}$（强人脸响应）
- $\Delta_{\text{Object}} = -0.5\text{ dB}$（反向抑制）
- $\Delta_{\text{Body}} = -0.8\text{ dB}$（反向抑制）
- $\Delta_{\text{Place}} = -0.3\text{ dB}$（反向抑制）

此时算出来的四类别均值：
$$\text{gen\_eff} = \frac{+5.0 - 0.5 - 0.8 - 0.3}{4} = +0.85\text{ dB}$$
在置换检验中，由于 $+0.85\text{ dB}$ 足够大，它极有可能被判定为 $p < 0.05$ 显著。

但这绝不是一个“色彩敏感电极”！在非人脸刺激下，彩色反而比灰度能量更低。它本质上是一个“人脸选择性电极（Face-selective electrode）”。

---

### 4.2 三种一致性分类定义

```matlab
if all(cat_diffs > 0)
    concord_type = 'Concordant_Positive';
elseif all(cat_diffs < 0)
    concord_type = 'Concordant_Negative';
else
    concord_type = 'Category_Biased';
end
```

| 分类名称 | 判定条件 | 神经生物学含义 | 在结果筛选中的地位 |
| :--- | :--- | :--- | :--- |
| **Concordant_Positive**<br>（总体正向增强） | $\Delta_{\text{Face}} > 0$<br>$\Delta_{\text{Object}} > 0$<br>$\Delta_{\text{Body}} > 0$<br>$\Delta_{\text{Place}} > 0$ | 无论是看到彩色的人脸、物体、身体还是风景，该电极诱发的脑电能量**全部一致地高于**灰度图。 | **最核心、最纯粹的色彩激活电极**。<br>后续可视化与跨条件解码的核心候选。 |
| **Concordant_Negative**<br>（总体负向抑制） | $\Delta_{\text{Face}} < 0$<br>$\Delta_{\text{Object}} < 0$<br>$\Delta_{\text{Body}} < 0$<br>$\Delta_{\text{Place}} < 0$ | 四大类别呈现完全一致的**色彩抑制效应**（常见于低频 Alpha/Beta 的去同步化抑制 ERD）。 | 重要的抑制性/调控性色彩电极。 |
| **Category_Biased**<br>（类别偏向 / 不同向） | 4 个类别符号正负混杂 | 该电极在某些类别呈现正效应、在某些类别呈现负效应，受到高层语义分类的强烈干扰。 | 剔除出通用色彩候选，作为语义/色彩交叉调制通道单独考察。 |
