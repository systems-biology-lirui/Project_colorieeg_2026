## 1. 数学原理：从高维超平面到一维数轴切割

### 1.1 高维 SVM 决策面
在经典的 $D$ 维特征空间中（例如我们联合 6 个频段时，$D=6$），每个试次 $i$ 对应一个 $D$ 维特征向量 $\mathbf{x}_i = [x_{i,1}, x_{i,2}, \dots, x_{i,D}]^T$。

线性 SVM 的目标是寻找一个分离超平面（Hyperplane）：

$$f(\mathbf{x}) = \mathbf{w}^T \mathbf{x} + b = 0$$

- 在二维平面（$D=2$）上，决策超平面是一条**分割直线**；
- 在三维空间（$D=3$）上，决策超平面是一个**分割平面**；
- 在六维空间（$D=6$）上，决策超平面是一个**五维超平面**。

对任意测试样本 $\mathbf{x}_{\text{test}}$，预测类别由决策函数符号决定：

$$\hat{y} = \text{sign}(f(\mathbf{x}_{\text{test}})) = \text{sign}(\mathbf{w}^T \mathbf{x}_{\text{test}} + b)$$

---

### 1.2 一维（单特征）SVM 的退化形式
当只选择**某一个单一频段**（例如仅使用 High-Gamma 频段能量），特征维度 $D=1$。
此时，每个试次 $i$ 的特征不再是多维向量，而是一个纯量（标量）实数 $x_i \in \mathbb{R}$（即该试次在当前时间窗内的能量分贝值 dB）。

此时，权重向量 $\mathbf{w}$ 退化为一个**单一实数斜率（方向标量）** $w \in \mathbb{R}$，决策方程变为：

$$f(x) = w \cdot x + b = 0$$

解该方程可得决策分界点（超平面）：

$$x^* = -\frac{b}{w}$$

也就是说：
在一维空间（数轴）中，**“超平面”就是一个点（即最优分类阈值 $x^*$）！**

分类判决准则极其纯粹直接：
- 若 $w > 0$（红色记忆能量整体高于绿色）：
  $$\hat{y} = \begin{cases} +1 \ (\text{Red}), & \text{若 } x \ge x^* \\ -1 \ (\text{Green}), & \text{若 } x < x^* \end{cases}$$
- 若 $w < 0$（红色记忆能量整体低于绿色）：
  $$\hat{y} = \begin{cases} +1 \ (\text{Red}), & \text{若 } x \le x^* \\ -1 \ (\text{Green}), & \text{若 } x > x^* \end{cases}$$

SVM 的凸优化目标（最大化几何间隔 Margin）：

$$\min_{w, b} \frac{1}{2} w^2 + C \sum_{j} \max(0, 1 - y_j (w \cdot x_j + b))$$

它在做的事情就是：**在数轴上寻找一个最佳切分点 $x^*$，使得两类数据点不仅被分开，而且离该切分点的间距（Margin $= \frac{1}{|w|}$）尽可能最大化。**

---

### 1.3 数轴几何直观示意

```text
一维特征数轴（例如 High-Gamma 能量 dB）:

               [Green 试次]                       [Red 试次]
       o    o   o     o    o               *    *     *    *   *
   <---|----+---+-----+----+-------|-------+----+-----+----+---+---> 
                                 阈值 x*
                               (w*x + b = 0)
                               
   <--------- 判定为 Green --------|--------- 判定为 Red --------->
```

从图中可以清晰看出，一维特征不仅完全能够做分类，而且分类逻辑在数学上是最干净、最可解释的。

## 2. 为什么单特征不直接用 t 检验，而要用 Decoding？

既然单频段只是数轴上的一个数值，很多研究者初接触时会问：“为什么不直接算红色记忆试次和绿色记忆试次的均值做个 $t$ 检验（或 ANOVA），而一定要大费周章做 SVM Decoding？”

这触及了现代认知神经科学中 **“Encoding（单变量编码分析）”** 与 **“Decoding（预测解码分析）”** 的核心区别：

### 2.1 统计差异（In-sample Difference） vs 泛化预测（Out-of-sample Prediction）
- **传统统计（$t$ 检验）**：
  将手头**所有的试次**混在一起计算 $p$ 值。只要样本量足够大，即使红绿均值只相差微不足道的 $0.01\,\text{dB}$，也能得到 $p < 0.05$。但这绝不代表大脑真的在用这个指标作为“稳健的记忆读取特征”，极容易产生假阳性或样本内过拟合（In-sample Overfitting）。
- **Decoding（机器学习分类）**：
  强调的是**泛化与预测（Generalizability & Prediction）**。它要求算法在“训练集”上学到的阈值 $x^*$，必须在完全独立的“测试集”上达到高于 $50\%$（机会水平）的准确率。

---

### 2.2 跨水果配对留一法（Leave-One-Fruit-Pair-Out）的严格约束
在当前 Task 2 的设计中，Decoding 发挥了传统 $t$ 检验无法做到的关键作用：**剔除形状混淆**。

试想：草莓、西瓜是红色记忆；卷心菜、猕猴桃是绿色记忆。
- 如果做普通 $t$ 检验，草莓和卷心菜的外轮廓差异（边缘/圆度/局部对比度）完全可能导致神经元放电不同，使得 $t$ 检验显著，但这种显著是**水果几何形状引起的**，而不是真正的“颜色记忆”！
- 但在我们的 4 折跨水果 Decoding 中：
  - 训练集：`草莓` vs `卷心菜` $\rightarrow$ 学习阈值 $x^*$；
  - 测试集：`西瓜` vs `猕猴桃` $\rightarrow$ 用 $x^*$ 去切分西瓜和猕猴桃！

**如果该频段能量只是反映了草莓的外形，那么这个阈值在西瓜和猕猴桃上就会彻底失效（准确率落在 50% 甚至更低）！**
唯有当 High-Gamma 能量真正代表了**跨越所有水果外形的“抽象红色 vs 绿色记忆概念”**时，测试集上的 Decoding 准确率才能达到 58.13% 并通过置换检验！

## 3. 在当前代码中单频段是如何计算的？

### 3.1 当前流水线的特征提取方式

```matlab
% 遍历每一个时间窗 w (窗长 50ms)
for w = 1:n_win
    % X_wb 是当前通道、特定频段 b 在当前 50ms 窗内的试次能量均值
    % 其维度是 [n_gray x 1] 的列向量
    X_wb = double(X_3d(:, b, w));
    
    for f_i = 1:n_folds
        % 训练集与测试集掩码
        tr_m = fold_tr_masks(:, f_i);
        te_m = fold_te_masks(:, f_i);
        
        % 标准化
        mu = mean(X_wb(tr_m));
        sig = std(X_wb(tr_m));
        X_tr_s = (X_wb(tr_m) - mu) ./ sig;
        X_te_s = (X_wb(te_m) - mu) ./ sig;
        
        % 训练一维线性 SVM
        mdl = fitclinear(X_tr_s, y_tr, 'Learner', 'svm', 'Regularization', 'ridge', 'Lambda', 0.01);
        
        % 在未见过的水果上预测
        y_pred = predict(mdl, X_te_s);
        
        % 计算测试集平衡准确率
        ...
    end
end
```

### 3.2 为什么这样设计？
1. **时程分辨率极高**：
   通过滑动窗口（50 ms 窗，20 ms 步长），我们能精准定位到**“在刺激呈现后第几毫秒，哪一个特定频段携带了颜色记忆信息”**。
   例如：我们发现 `sub001-G13` 的 High-Gamma 在 760~780 ms 达到 58.13%，而早期 200 ms 只有 50%，这精确揭示了记忆提取的潜伏期（Latency）。
2. **消融对照（Ablation Baseline）**：
   对比 6 频段联合特征（6 维）与各单频段（1 维），能回答一个关键神经科学问题：
   **“多频段联合是否带来了协同增益？还是某些频段引入了噪声？”**
   结果显示：在 `sub007-C4` 上，6 频段联合只有 53.95%，而 Low-Gamma 单频段达到 58.77%，这直接证明了多频段简单拼接存在噪声稀释，单频段反而更干净。

## 4. 单频段 Decoding 的拓展可能性（如何构建多特征？）

如果你希望在单频段分析中引入更多的特征维度（即不希望单频段只有 1 个特征），神经电生理中有两种常见的扩展方案：

### 方案 A：时间维度展开（Temporal Pattern Decoding）
- **做法**：在 50 ms 的窗口内，不取均值，而是把该窗口内的每一个采样点都作为独立特征。
- **特征维度**：若采样率为 500 Hz，50 ms 窗内包含 25 个时间采样点。此时单频段的特征维度为 **25 维**。
- **特点**：分类器不仅利用能量高低，还能利用这 50 ms 内部的动态上升/下降斜率（Temporal Trajectory）。

### 方案 B：空间多通道联合（Spatial Pattern Decoding）
- **做法**：如果分析不局限于单个电极，而是选取某个脑区（如枕叶或梭状回）的 10 个电极。
- **特征维度**：每个电极提供该频段的一个能量值，特征维度为 **10 维**。
- **特点**：利用电极之间的空间能量分布拓扑图进行解码（经典的脑电地形图模式解码）。

## 5. 总结

1. **单频段只有 1 个特征，完全可以做 Decoding**：
   线性分类器在数学上寻找数轴的最优分割阈值点，理论严密、运行高效。
2. **单特征 Decoding 的核心价值在于跨条件交叉验证**：
   它排除了外形轮廓等低级视觉混淆，严格检验了“单个频段指标是否独立具备抽象颜色概念的泛化表征能力”。
3. **实验结果的高度一致性**：
   `sub001-G13` 的 High-Gamma（58.13%）与 `sub007-C4` 的 Low-Gamma（58.77%）不仅能被成功解码，而且准确率超越了 6 频段联合拼接，为后续频段特征筛选提供了扎实的证据。
