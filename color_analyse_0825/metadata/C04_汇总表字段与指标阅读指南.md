# C04 全频段色彩统一效应汇总表阅读指南

数据表文件：`color_analyse_0825/metadata/C04_全频段色彩统一效应汇总.csv`

---

## 1. 表格的整体结构（数据组织方式）

该表格是 8 位被试、所有可用电极通道在 6 大频段下的完整统计大表：
- **每一行**：代表一个特定的**【被试 + 电极通道 + 生理频段】**三元组（例如 `test001` 的 `D14` 电极在 `High_Gamma` 频段的响应）。
- **总行数**：全脑 8 位被试共有 793 个有效 Laplacian 双极重参考通道，每个通道分别评估 6 个频段（Delta, Theta, Alpha, Beta, Low_Gamma, High_Gamma），共计：
  $$793 \times 6 = 4758 \text{ 行记录}$$

---

## 2. 四大核心指标的定义与生物学意义

在主分析窗口（$[100, 400] \text{ ms}$）内，对单张图片配对色彩效应差值 $d_i = \text{Color}_i - \text{Gray}_i$ 进行跨类别统计时，定义了以下四个互斥或层级指标：

### ① 显著通道数 ($p < 0.05$)
- **定义**：通道在该频段上的 4 类别等权平均色彩总效应 $\Delta_{\text{unified}}$ 是否显著异于 0：
  $$\Delta_{\text{unified}} = \frac{1}{4} \left( \bar{d}_{\text{Face}} + \bar{d}_{\text{Object}} + \bar{d}_{\text{Body}} + \bar{d}_{\text{Place}} \right)$$
  经过 $N_{\text{perm}} = 2000$ 次随机符号翻转置换检验，置换双侧 $p < 0.05$（对应表中 `is_significant == 1`）。
- **通俗含义**：这个电极在看彩色和看灰度时，大脑信号的差别**不是由于随机噪声波动引起的，在统计学上是真实存在的效应**。

---

### ② 四类一致正向增强 (Concordant Positive)
- **数学条件**：
  1. $p_{\text{perm}} < 0.05$（统计显著）；
  2. $\Delta_{\text{unified}} > 0$（总效应为正）；
  3. $\bar{d}_{\text{Face}} > 0, \; \bar{d}_{\text{Object}} > 0, \; \bar{d}_{\text{Body}} > 0, \; \bar{d}_{\text{Place}} > 0$（四大类别的色彩差值**全部严格大于 0**）。
- **通俗含义**：**“跨类别的纯粹色彩激活电极”**。
  - 不管画面呈现的是人脸、普通日常物品、人体躯干还是自然建筑场景，只要图片是彩色的，该脑区的神经元活动（或振荡功率）都稳定强于黑白灰度图片。
  - 它证明该脑区在执行**全局、泛化的色彩感知与特征提取**，而不是仅仅喜欢某一种特定物体。

---

### ③ 四类一致负向抑制 (Concordant Negative)
- **数学条件**：
  1. $p_{\text{perm}} < 0.05$（统计显著）；
  2. $\Delta_{\text{unified}} < 0$（总效应为负）；
  3. $\bar{d}_{\text{Face}} < 0, \; \bar{d}_{\text{Object}} < 0, \; \bar{d}_{\text{Body}} < 0, \; \bar{d}_{\text{Place}} < 0$（四大类别的色彩差值**全部严格小于 0**）。
- **通俗含义**：**“跨类别的纯粹色彩抑制或去同步化电极”**。
  - 在四大类别下，彩色引起的信号功率全部显著低于灰度。
  - **典型生理机制（Alpha 去同步化）**：
    在视觉皮层中，Alpha 节律（8–12 Hz）通常代表皮层的基底抑制态。当人脑接收到高信息量、高显著性的彩色刺激时，大脑皮层会进入强烈的兴奋激活状态，促使 Alpha 振荡急剧降低（称为事件相关去同步化，ERD）。因此在 Alpha 频段，强烈的负向差值（如 $\Delta = -2.0 \text{ dB}$）恰恰是大脑受到彩色强烈激活的典型生理标志。

---

### ④ 类别偏向通道数 (Category Biased)
- **数学条件**：
  1. $p_{\text{perm}} < 0.05$（统计总体是显著的）；
  2. 但四大类别之间的效应符号**发生了打架或翻转**（例如：$\bar{d}_{\text{Face}} > 0$，但 $\bar{d}_{\text{Place}} < 0$）。
- **通俗含义**：**“掺杂了语义偏好或类别特异性的非纯色彩电极”**。
  - 例如，某电极只在看人脸时彩色强于灰度（可能因为人脸肤色、血色对社交认知极其重要），但在看无生命的桌子椅子或风景建筑时，彩色反而不如灰度或者没有差别。
  - 这种通道**不能作为广义的色彩选择性位点**，否则会把“人脸识别效应”或“高低级语义交互”误当做是纯粹的“色彩物理加工”。

## 3. CSV 关键列字段速查表

| 列名 (Column) | 含义解释 | 典型取值示例 | 筛选建议 |
| :--- | :--- | :--- | :--- |
| `subject` | 被试编号 | `test001` ~ `test008` | 按被试查看 |
| `channel` | 电极中心触点 | `D4`, `G13`, `A3` | 目标电极 |
| `laplacian_triplet` | 双极重参考公式 | `D4-(D3+D5)/2` | 核对参考结构 |
| `freq_band` | 频段名称 | `High_Gamma`, `Alpha` 等 | **必选**：筛选关注频段 |
| `stream_hierarchy` | 视觉层级前后侧 | `Posterior_Upstream` / `Anterior_Downstream` | 划分早视区与高阶区 |
| `is_votc_roi` | 是否处于腹侧视通路 | `1` (是), `0` (否) | 聚焦 VOTC 核心脑区 |
| `dkt_anatomy` | FreeSurfer DKT 解剖定位 | `Lateral occipital R`, `Fusiform R` | 解剖脑区定位 |
| `mni_x, mni_y, mni_z` | 标准空间 MNI 坐标 | $Y < -60$ 为后侧，$Y \ge -60$ 为前侧 | 定位前后轴 |
| `general_effect_100_400ms` | 主时间窗四类等权色彩效应 | 例如 `+0.49` dB 或 `-2.03` dB | 效应量大小 |
| `p_perm_100_400ms` | 置换检验双侧显著性 $p$ 值 | 例如 `0.0110` | 越小越显著 |
| `concordance_type` | **类别一致性分类** | `Concordant_Positive` / `Concordant_Negative` / `Category_Biased` | **核心筛选列** |
| `delta_face_dB` 等 4 列 | 各类别单项色彩效应 | 例如 Face `+0.49`, Object `+0.51` | 检查四类差值 |
| `is_significant` | 是否统计显著 ($p < 0.05$) | `1` (显著), `0` (不显著) | **首要筛选列：选 1** |

## 4. 如何在 Excel 中高效筛选出高价值电极？

1. **第一步（过滤噪声）**：
   在 `is_significant` 列筛选出 `1`（只看通过置换检验的显著通道）。
2. **第二步（选择纯粹色彩电极）**：
   在 `concordance_type` 列勾选 `Concordant_Positive`（看正向激活通道）或 `Concordant_Negative`（看抑制/去同步通道），排除掉 `Category_Biased`。
3. **第三步（选择特定生理机制与频段）**：
   - 如果想找**神经元放电增强位点**：在 `freq_band` 选 `High_Gamma` 或 `Low_Gamma`，且 `concordance_type` 为 `Concordant_Positive`。
   - 如果想找**皮层兴奋去同步化位点**：在 `freq_band` 选 `Alpha`，且 `concordance_type` 为 `Concordant_Negative`。
4. **第四步（结合解剖定位）**：
   查看 `dkt_anatomy` 和 `mni_y`，挑出位于外侧枕叶（Lateral Occipital）、舌回（Lingual）、梭状回（Fusiform）的核心位点。
